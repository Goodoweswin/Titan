# 免疫荧光开发版验证记录

日期：2026-11-03。源码分支 codex/immunofluorescence，功能提交 a2024d1。本次未创建 GitHub Release，发布条件尚未全部满足。

## 已实现

二维 TIFF/OME-TIFF 多通道与分通道导入、独立 .titanif 项目、原始坐标区域、区域强度/阳性面积、DAPI 分水岭分割、人工补删/合并/拆分/撤销、显式核确认、核内强度/阳性率、同批次模板与批处理、对象/视野/生物学样本表、独立组图、PNG/TIFF/SVG 与 CSV/XLSX/样本散点图、自动保存与来源校验。

原始像素、显示映射和分割数据分离。原图、确认/人工编辑标签及完整结果均正式持久保存；传输预览限制每视野500条、每项目5000条，完整对象表保留在校验的结果文件中。超出 JavaScript/Excel 精确范围的整数使用十进制文字保存。区域模式不产生核阳性率；核模式需要已确认且未过时的标签。

## 审阅修正

独立代码审阅发现并修正：区域阳性被误作核阳性、组图预览超过通信上限、多序列导入附带不存在的轴、密集核编号截断导致无法修正、Excel大整数末位丢失、缺失生物学编号被合并成样本、人工标签缺少撤销入口，以及后台启动时的重复任务窗口。修正均有回归证据；限定范围复查未发现未解决的重要问题。

最终预览预算接入曾误放在路径解析返回处，由五项原有持久化测试检出，已改在项目响应边界执行；随后完整 Python 258项与7项实际 IF 浏览器流程再次通过。未留下该错误的发布资产。
