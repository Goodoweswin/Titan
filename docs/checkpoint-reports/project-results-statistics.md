日期：2026-11-07（本地）。基础 `a4c0711` / `v0.4.0-beta.3`，版本仍为 0.4.0 本机测试构建。

## 已实现

- 统计模块直接读取保存的 WB / IF 项目，按指标预览分组、独立 n、缺失与单位，可新建统计项目或追加数据表。
- WB / IF 结果页均进入统一选择窗口；统计来源栏可返回原模块、检查变化、显式更新或复制可编辑表。
- IF 按生物学样本合并视野的分子与分母，支持平均强度、扣背景总强度、阳性面积百分比和核阳性率；不同采集批次分表。
- 部分视野未测量、通道结果缺失、零分母保持缺失；过期结果和不兼容阈值阻断读取。明确 ID 控制配对，不使用视野数或核数增加独立 n。
- 读取前后校验来源签名；来源值只读，显式更新后保留历史分析及冻结图，来源失联时仍能使用快照。
- 修正统计与 IF 弹窗定位；未保存 WB 项目发送前先保存，取消保存不跳转。

## 原生检查发现的精度问题

在原生 WB 关联表中运行分析后，自动保存被只读检查拒绝。新增 Rust→Python 实际工作流回归先复现相同错误，再启用 `serde_json` 的 `float_roundtrip` 特性后通过。问题来自通信解析对部分浮点数的微小改变，修复没有放宽只读检查。最终包已重新构建并通过签名校验。
