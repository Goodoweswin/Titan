# Titan 0.3.0 功能与界面合并

## 来源与范围

以 `codex/lane-first-analysis` 的 `f1de6e1914a59e17bda3a8bf258cb32fa27cf543` 为功能基线，将当前工作区快进到该历史，再合并已确认的视觉改动。原工作区源码已归档到本地 `artifacts/merge-0.3.0/desktop-before-merge.tar.gz`，旧 HEAD 保留于 `refs/codex/backups/`。

- 版本保持 `0.3.0`；应用名称统一为 Titan，项目格式与应用标识保持原值。
- 平滑拳头用于桌面图标、工作台与 favicon；猩猩头用于处理状态。
- 简洁首页移除口号、品牌副标题及版本尾注；Western blot 与免疫荧光并列，后者仅标记“待开发”。
- 保留泳道优先分析、常驻引擎、自动项目库、论文图配置、冻结图表历史、多组统计及 Excel 导出。
- 业务后端、原生 worker、泳道和图表组件与功能基线一致；App 的状态、分析、保存和图表历史逻辑保持原样，仅修改展示、产品名称和加载图形。
- 发布工作流从 package.json 读取版本，包验证同时核对应用元数据与实际计算引擎版本，防止版本不匹配。

- 原生引擎：6 个 Rust 测试通过。

- 桌面构建通过，应用与打包 worker 均为 0.3.0，签名检查通过。
