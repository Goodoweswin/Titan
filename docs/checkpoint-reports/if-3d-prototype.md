# Titan 免疫荧光 3D 查看原型实测

2026-11-07，Apple M4 Mac，macOS 26.5（25F71）。使用含本地计算引擎的 Titan IF 3D 开发版，在原生 Tauri 窗口内打开图像。性能按钮通过构建选项 `VITE_TITAN_IF_BENCHMARK=1` 启用。

| 数据 | 原始及显示体素 | 首次出图 | 十秒旋转中位帧率 | P95 帧间隔 |
|---|---:|---:|---:|---:|
| Allen Institute C70935，CMDRP、EGFP、H3342 | 215 × 201 × 52，三通道 | 2.04 s | 71.4 FPS | 15.0 ms |
| 固定合成性能堆栈，DNA、Actin、Membrane | 512 × 512 × 40，三通道 | 0.71 s | 71.4 FPS | 15.0 ms |

两组均为 16 位数据，在这两次测试中显示体素没有缩减。首次出图从「加载 3D 视图」开始计时，包含解码、数据传输和首次渲染，文件选择和元数据确认在计时前完成。合成堆栈是在同一窗口换图后测得，渲染组件已经加载。十秒旋转由视图内的测试按钮在 960 × 720 像素下连续转动相机，并等待 GPU 完成每帧后记录帧间隔。这个指标反映渲染吞吐，屏幕实际呈现帧率还受刷新率影响。固定堆栈达到首次出图 ≤5 s 和中位帧率 ≥30 FPS 的原型目标。

- 原生手动验收覆盖真实堆栈打开、三通道叠加、通道显示控制、旋转、缩放、正交切片、调整切片位置、换图，以及通过系统对话框导出 3D 和 XZ PNG。3D PNG 解码为 1134 × 648 像素，三种伪彩均有有效像素。合成堆栈关闭两个通道后导出的 PNG 只剩蓝色信号。XZ PNG 的长宽比与 XYZ 标定一致。导出后确认临时体素文件已释放。
- 自动测试核对合成数据的 T/C/Z 顺序、XYZ 标定、ZYXC 体素值、三个正交方向坐标、仅 XY 降采样、缺失标定、不等距和矛盾 Z 标定、超限、取消，以及会话隔离的二进制读取。通过 264 项 Python 测试及 5 项子测试、76 项前端测试、7 项 Rust 测试、57 项 IF/WB 浏览器回归和打包引擎的 IF/WB 冒烟验证。
- 真实样本是 Allen Institute 公共荧光显微数据，文件 `AICS-12_228_70935.ome.tif`，SHA-256 `c896ee0d4bea38fd5a5c28a48f43fcbf3f8e1ec31f3469f760ae00ae9be92b25`。合成性能文件 `benchmark-512-3ch.ome.tif`，SHA-256 `87266f0b654237fdf1e08edf4421926330c5708e99adace57f31eef416d2336b`。真实样本验证了渲染和交互，IF 定量准确性和 Windows 原生表现各自仍待验证。[样本来源](https://forum.allencell.org/t/agave-download-problem/174)
