# Titan WB 0.2.0 本机更新验收记录

2026-11-01，macOS / Apple Silicon。本次更新已安装到 `/Applications/Titan WB.app`；源码保留在独立 `codex/lane-first-analysis` 分支。未发布 GitHub Release，未合并或覆盖原工作目录的未提交源码。

## 已实现的行为

默认操作为“内参 → 目标 → 结果”。内参建立稳定泳道与样本对应，后续目标复用身份并允许手动对齐。每泳道分别建议峰区、背景与曲线，需确认后才生成正式测量。未检出保留空槽位，不补位、不自动记 0。结果自动按同膜、同泳道、明确关联的内参归一化；生物学汇总和统计须另行确认实验设计。

支持灰度调色板、MINISWHITE、8/16 位原图及多页 TIFF 选页。显示反色只改变预览，测量仍读取所选页原始像素。引擎常驻并使用有界缓存，原图哈希在定量前仍会检查。旧 v1 项目升级后首次保存须另存副本。

最终审查发现 5 个 Important、1 个 Minor，已一次集中修复：压缩 8 位 MINISWHITE 自动反色、重新识别的样本错配风险、结果分母与显示内参不一致、手动编辑破坏集合、预览后改名仍保存旧名，以及反色使建议过期。重新识别现在复用明确模板，不按最近坐标猜测身份；集合内的身份字段在简洁流程中修改，手动删除转为待确认槽位。

## 数值和实际 TIFF 检查

已知合成原图：目标 16 px × 3000 = 48000，背景均值 1000，净积分 32000；参考净积分 8000；比值 **4**。打包引擎结果与手算完全一致，绝对差为 0。第二泳道目标未检出，其比值为 null。反色、保存重开和审计导出后数值不变。该检查未使用 Fiji，不能称为独立 Fiji 对照；另附 `scripts/fiji_reference.ijm` 和生成夹具脚本供后续复核。

本地 `108603.tif` 的第 1 页 uint8 灰度反向 LUT、第 2 页 uint16 均可检查和导入。对原始页选定区域的积分、背景均值与直接数组计算一致；导入前后源文件 SHA256 一致。额外覆盖 LZW MINISWHITE 的 uint8 和 uint16，证明解码不改变编码数值。实际文件仅做格式与原始像素检查，没有推断蛋白身份、真实样本数或生物学准确性；未把原文件加入源码。

## 最终包性能

同一台机器，12,413,842 字节的本地 TIFF，最终 ad-hoc 签名 App 的目录副本，5 个新 worker，每次检查 → 预览 → 导入第 2 页。各序列只启动一次 worker。

| 分项，秒 | 中位数 | 最大值 |
|---|---:|---:|
| 新 worker 到 health 响应 | 0.073 | 0.781 |
| 页面列表 | 0.039 | 0.098 |
| 选页预览 | 0.072 | 0.074 |
| 已预览页导入 | 0.0061 | 0.0065 |

第一次新副本启动 0.781 秒；其余启动约 0.07 秒。本机本组样本满足计划中 3/1/1/2 秒的分项目标。此前单文件引擎在本机每次启动约 15–23 秒；中间未签名目录构建首次启动仍有 16 秒开销，不能拿其后热启动掩盖。上述最终包测速不含文件选择和人工确认，不代表完整 UI 延迟，也未清除 macOS 文件缓存，不能保证其他机器或首次下载后的时间。
