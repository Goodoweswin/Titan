日期：2026-11-02。范围为本地开发版，未发布或重新打包安装程序。

## 已实现

- 独立的“WB 组图”视图，不依赖定量结果。
- 整行连续原图裁剪，支持拖动与整数坐标；目标蛋白默认在内参前。
- 蛋白名、预期分子量、按原图位置放置的 marker、顶部条件标签。
- 85 mm / 8 pt / 3 mm 默认版式；宽度、字号、间距和行顺序可调；保持图像比例。
- 组图草稿、独立撤销/重做、版本保存、重新打开及项目副本迁移。
- PNG（300/600 DPI）、嵌入位图且文字可编辑的 SVG、来源 JSON。
- 全幅显示映射、TIFF 页号、旋转、原始文件哈希和裁剪来源记录；原图保留在项目内。

## 独立审阅与修正

独立审阅未发现 Critical 问题，报告的四项 Important 已增加回归并修复：

1. 撤销/重做只恢复编辑内容，保留最新持久化版本，避免保存后撤销导致版本冲突。浏览器回归读取真实 `wb_save` 成功响应；恢复旧实现时确认失败。
2. 应用复制与组图加载/保存互斥；异步文档响应同时校验项目上下文，路径变化使过期请求失效。
3. 灰度调色板先映射为强度再进行旋转插值，测试非线性/反向 LUT、非直角旋转与部分裁剪。
4. 首次保存实验允许授权的初始路径赋值，一次操作完成实验与组图保存，保留当前草稿。

另修正了变量字体默认 Thin 与 SVG 正常字重不一致的问题，PNG 使用 Regular；以字体掩模回归确认。
