Titan 0.3.3 beta.2 测试版。包含已合并到 main 的 WB 条带组图和新工作区，并统一应用与计算引擎版本。

## 下载

- `Titan-0.3.3-macos-arm64.dmg`：macOS 14+，Apple Silicon（M 系列）。
- `Titan-0.3.3-macos-arm64.app.zip`：相同 Mac 应用的 ZIP 归档。
- `Titan-0.3.3-windows-x64-setup.exe`：Windows 10/11 x64 安装程序。
- 两个平台的 `*-third-party.zip`：第三方许可清单和原文。
- `SHA256SUMS.txt`：发布文件 SHA-256 校验值。

## 本次更新

- 新增独立 WB 条带组图：从连续原图区域裁剪条带，添加蛋白名称、预期分子量、marker 和实验条件，调整布局后导出 PNG、带嵌入条带图和可编辑文字的 SVG，以及来源记录。无需先做定量。
- 组图独立保存、版本保护、重开和便携副本；核验原图哈希、页码、裁剪坐标和旋转，保留来源。
- 统一灰白工作区、深色主要按钮和紧凑顶栏；保留大字号、键盘操作、只读保护、引擎状态及 WB 草稿补充原图。
- 保留此前泳道定量、旋转校正、结果页标签、统计出图和 Excel 导出。
- 应用、计算引擎及安装文件统一版本为 0.3.3。

## 升级

先保存实验并退出旧版，再安装。应用身份仍为 `com.titan.wb`，保留既有项目库；旧格式项目按提示另存副本。

## 验证范围

本次发布检查 Python、前端、浏览器和生产构建，并在 macOS arm64、Windows x64 原生 runner 构建安装包及验证实际打包引擎。检查包括泳道定量、保存重开、论文图和 Excel、旋转原始像素，以及本版新增 WB 组图保存、版本冲突、便携副本和预览/导出一致性。

实际通过情况见本标签 Actions 和 [发布验证记录](v0.3.3-beta.2-verification.json)。真实 WB 科学准确性和完整跨平台原生桌面验收仍待完成。Mac 为临时签名、尚未公证；Windows 未配置商业签名。自动化和合成数据检查不代替真实实验验证。

发布修复：beta.1 在 Windows 打包引擎的中文 WB 组图保存检查中被阻止，未发布安装附件。beta.2 明确以 UTF-8 读取组图文档、索引及项目标识，新增非 UTF-8 系统默认编码下的中文保存重开回归检查。
