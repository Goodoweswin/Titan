首次完整开源测试版，采用 MIT 许可证。应用内部版本为 0.1.0。

## 下载

- `Titan-WB-0.1.0-macos-arm64.dmg`：macOS 14+，Apple Silicon（M 系列）。
- `Titan-WB-0.1.0-macos-arm64.app.zip`：相同 Mac 应用的 ZIP 归档。
- `Titan-WB-0.1.0-windows-x64-setup.exe`：Windows 10/11 x64 安装程序。
- `*-third-party.zip`：各平台的第三方依赖许可清单和原文。
- `SHA256SUMS.txt`：发布文件校验值。

应用包含 Python 计算引擎。Windows 缺少 WebView2 时需联网安装该运行库。

## 本次功能

原始灰度图像定量、可编辑 ROI、候选识别确认、局部背景与强度曲线、样本及重复映射、归一化与两组统计、项目保存和审计导出、真实出图预览、浅色大字号界面。

## 验证范围

发布流程在 Windows x64 和 macOS arm64 原生 runner 构建并执行测试；Mac 打包引擎另做独立副本、保存重开和导出检查。具体结果见对应 Actions 记录。

这是预发布版本。真实 WB 准确性和完整原生窗口操作验收仍待完成。macOS 包采用临时签名、尚未公证；Windows 包未配置商业代码签名。所有合成示例均为非实验数据。

使用与开发说明见仓库 README 和 docs/USER_GUIDE.md。
