Titan 0.4.0 beta.3 加入独立免疫荧光模块，并更新 Western blot 首页和操作指引。

beta.1 遇到 GitHub 的 macOS 14 构建环境退役。beta.2 改用 macOS 15 后，Windows 免疫荧光任务检查仍未通过。beta.3 修复任务记录的 UTF-8 读取，并在切换免疫荧光项目期间暂停导入。应用内部版本为 0.4.0。

## 本次更新

- **免疫荧光**支持 TIFF / OME-TIFF 通道与平面选择、区域强度和阳性面积测量、DAPI 核分割与人工修正、批量测量和论文组图。实验使用独立的 `.titanif` 格式。
- **Z-stack 三维查看（原型）**支持在本机打开规则 OME-TIFF 堆栈、叠加最多三个通道、旋转缩放、查看 XY／XZ／YZ 切片并导出 PNG。
- **Western blot**首页新增图像操作指引。点左栏模块名称可回首页，点「继续当前实验」可恢复原视图及未确认的组图草稿。共用项目库可直接打开两个模块的项目。

## 下载与升级

- macOS 14+ Apple Silicon 使用 `Titan-0.4.0-macos-arm64.dmg` 或应用 ZIP。
- Windows 10/11 x64 使用 `Titan-0.4.0-windows-x64-setup.exe`。
- 校验值和第三方许可分别见 `SHA256SUMS.txt` 与两个平台的许可 ZIP。

保存实验、退出旧版后再安装。应用标识保留为 `com.titan.wb`，可继续打开原 WB 项目。

## 验证范围

自动化回归覆盖 WB、免疫荧光、跨模块打开项目和 Z-stack 体素读取。两平台安装包使用 GitHub Actions 原生构建，并检查实际打包引擎的泳道、论文图、旋转、WB 组图及免疫荧光流程。三维交互另有 Mac 开发版的实测记录，Windows 三维操作和正式安装包的完整原生界面验收仍待完成。

本版处于测试阶段。真实样本的三维显示实测与定量准确性验证分别进行，真实 WB 和 IF 的定量准确性仍待验证。macOS 包采用临时签名，尚未公证。Windows 安装包未配置商业签名。
