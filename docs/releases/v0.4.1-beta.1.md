Titan 0.4.1 beta.1 整合项目侧栏、WB／IF 结果对接和独立统计与绘图工作区。

- 左栏「项目 ＋」可手动创建课题，将 WB、免疫荧光和统计分析放在一起管理。分析自动保存，重新打开可恢复上次视图。课题的「图表与导出」可打开冻结快照和已登记的文件。
- WB 和 IF 结果页可发送到「统计与绘图」。选择指标、核对独立样本数和缺失值后，创建关联数据表。已登记的来源移位后可通过左栏重新定位。历史分析和冻结图保留原有数据。
- 独立统计工作区可调整柱图、原始点、误差线、颜色和标注，并导出 Excel、PNG、SVG、PDF 与方法说明。修复部分关联表因浮点往返精度变化而触发的保存误报。
- [版本注册表](INDEX.md)记录公开发布、构建、校验和本机安装。

macOS 14+ Apple Silicon 使用 DMG 或应用 ZIP，Windows 10/11 x64 使用安装 EXE。发布附件包含 `SHA256SUMS.txt` 及第三方许可清单。安装前保存并关闭当前实验。应用标识仍为 `com.titan.wb`。

发布检查包含两平台打包引擎的统计、来源关联和导出。真实 WB／IF 定量准确性与完整 Windows 原生界面验收仍需另行验证。
