Titan 0.4.2 beta.1 整合当前账户登录、项目导航、活动日历和统一菜单。Mac 与 Windows 安装包使用同一份源码，应用显示版本为 0.4.2。

- 账户位于应用中栏，通过系统浏览器登录自建 ECS 账户服务；支持昵称、登录设备和退出管理。长期登录凭据使用系统凭据库，本地科研功能仍可在未登录时使用。
- 账户服务目前按管理员开通模式运行。自助注册、验证邮件投递和邮件找回密码尚未开放；账号问题由管理员处理。Pilotus 账号合并及跨设备科研数据同步尚未接入。
- 保留正方形活动日历及每日／每周／累计视图、系统明暗外观、项目与分析导航。研究足迹仍为本机记录。
- 项目、分析、图表与导出使用统一的右键／省略号菜单；统计值通过菜单明确排除或恢复。保留 WB、IF、统计绘图和 PNG／SVG／PDF／Excel 导出。

下载：

- `Titan-0.4.2-macos-arm64.dmg`：macOS 14+，Apple Silicon（M 系列）。
- `Titan-0.4.2-macos-arm64.app.zip`：同一 Mac 应用的 ZIP 归档。
- `Titan-0.4.2-windows-x64-setup.exe`：Windows 10/11 x64 安装程序。
- `SHA256SUMS.txt` 与两个平台的 `*-third-party.zip`：文件校验和及第三方许可。

安装前保存工作并退出 Titan。应用标识保持 `com.titan.wb`；旧项目继续使用原有位置。macOS 可能重新要求确认受保护文件夹或钥匙串访问。

发布流程检查两平台的单元测试、实际打包引擎、版本一致性和原生程序内的 ECS 登录地址；这些自动化结果不等同于完整 Windows 原生登录／凭据库／界面验收，也不代替真实 WB／IF 科学准确性验证。Mac 包使用临时签名、尚未公证，Windows 未配置商业代码签名。本版继续作为测试版发布。
