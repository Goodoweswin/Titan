Titan 0.3.2 beta.1 测试版，更新结果分析工作区，保留 0.3.1 的分析、项目保存和导出能力。

## 下载

- `Titan-0.3.2-macos-arm64.dmg`：macOS 14+，Apple Silicon（M 系列）。
- `Titan-0.3.2-macos-arm64.app.zip`：相同 Mac 应用的 ZIP 归档。
- `Titan-0.3.2-windows-x64-setup.exe`：Windows 10/11 x64 安装程序。
- 两个平台的 `*-third-party.zip`：第三方依赖许可清单和原文。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

应用自带 Python 科学计算引擎和中文出图字体。Windows 缺少 WebView2 时需联网安装该运行库。

## 本次更新

- 结果分析分成“定量结果”“样本设置”“统计与图表”三个标签页，支持方向键、Home 和 End 切换。
- 样本表采用约 42px 紧凑行，去掉常驻输入边框；扩展字段收进“更多列”，选中泳道后显示批量操作。
- 图表设置放到预览右侧，切换标签保留未保存的图表样式；改善窄窗口中的表格滚动。
- 保留图像旋转校正、泳道边界微调、撤销重做、项目库、图形版本历史及 Excel 导出。

## 升级

保存正在进行的实验后退出旧版，再安装新版。旧格式项目按提示另存新副本；应用身份仍为 `com.titan.wb`，原有项目库继续使用。

## 验证范围

本版新增浏览器回归覆盖样本编辑、批量分组、样本表粘贴、图表草稿保留、键盘导航和窄窗口布局。发布流程在 Windows x64 和 macOS arm64 原生 runner 上运行测试、构建安装包，并检查实际打包引擎的泳道定量、项目保存重开、统计出图、Excel 导出与旋转后原始像素积分。实际通过情况以本标签的 Actions 结果和发布验证记录为准。

这是测试版。合成数据和自动化检查不代替真实 WB 科学准确性或完整原生桌面安装操作验收。Mac 包采用临时签名、尚未公证；Windows 未配置商业代码签名。
