# Titan 应用内更新

支持 Beta 更新的 Mac 版 Titan 在启动后会检查新版。发现新版时，左侧底部会显示「更新并重启」。

1. 保存正在处理的分析和组图。
2. 点击「更新并重启」。Titan 会下载并验证更新包。下载期间也可以选择「稍后安装」。
3. 重新启动后，在项目库中打开原来的项目。如系统提示访问项目文件夹，按提示选择所需的文件夹。

有分析任务、条带候选或组图草稿待处理时，Titan 会暂存已下载的更新包，等处理完再继续安装。历史安装包如果没有应用内更新入口，可从 Releases 下载最新 Beta 手动安装。

Windows x64 使用新版 EXE 手动更新。先保存工作并退出旧版，再运行新版安装向导。
