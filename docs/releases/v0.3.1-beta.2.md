Titan 0.3.1 beta.2 测试版，包含此前本地 0.3.0 的完整功能及最新图像、泳道交互修复。

## 下载

- `Titan-0.3.1-macos-arm64.dmg`：macOS 14+，Apple Silicon（M 系列）。
- `Titan-0.3.1-macos-arm64.app.zip`：相同 Mac 应用的 ZIP 归档。
- `Titan-0.3.1-windows-x64-setup.exe`：Windows 10/11 x64 安装程序。
- 两个平台的 `*-third-party.zip`：依赖许可清单和原文。
- `SHA256SUMS.txt`：全部发布文件的 SHA-256 校验值。

应用自带 Python 科学计算引擎和中文出图字体。Windows 缺少 WebView2 时需联网安装该运行库。

## 本次更新

- 应用统一命名为 Titan，更新图标、加载动画及简洁界面；免疫荧光与 Western blot 并列显示，标为“待开发”。
- 内参、目标、结果三步流程；稳定泳道身份、缺失槽位、逐泳道曲线、可复核的峰区和局部背景。
- 修复泳道模式误画区域、绿框拦截拖动、手柄超出视野、目标裁剪坐标套用及新目标模式残留。
- 内参和目标均支持单泳道平移、左右边界、1/10 像素键盘微调、整组移动、峰区/背景编辑与撤销重做；已确认测量先进入编辑草稿。
- 目标图像导入后自动切换；支持复用内参位置或独立识别目标位置，重新识别需明确核对样本编号，缺失条带不向前补位。
- 旋转校正保留原图；增加可拖动的水平、垂直参考线。校正画面用于识别，定量读取选框对应的原始像素。
- 本地自动保存项目库、冻结图表和版本历史；多组 ANOVA/Welch ANOVA 及相应比较；可配置论文图、含嵌图的 Excel 和完整审计导出。
- 修复重新框选、切换对应内参及撤销后的区域/引用同步。

## 升级

先确认并保存当前实验，再退出旧版并安装新版。旧格式项目按提示另存新副本；应用身份保留为 `com.titan.wb`，原有项目库继续使用。

## 验证范围

发布流程在 Windows x64 和 macOS arm64 原生 runner 执行单元测试、构建安装包，并验证实际打包引擎的泳道定量、保存重开、统计出图、Excel 导出及旋转后的原始像素积分。具体证据见本标签对应的 Actions 与校验文件。

这是测试版：真实 WB 科学准确性、完整原生桌面安装与操作验收仍需继续。Mac 包采用临时签名、尚未公证；Windows 未配置商业代码签名。合成测试不代替真实实验验证。

发布修复：Windows 虚拟环境启动器和实际引擎可能使用不同进程号。常驻检查改为比较多次响应的引擎身份，并明确 UTF-8 编码。beta.1 构建因此项测试被阻止，未发布安装附件。
