# Titan v0.4.5-beta.1

- WB 原图改用画布上方的页签切换。
- 切换图像时可保留尚未确认的修改。旧版保存的手动条带仍可打开、编辑和重新定量。
- 点选绿色条带框或橙色背景框后可直接拖动四边。条带框限制在所属泳道内，自动生成的背景框也能微调。
- 切换泳道时右栏保持稳定，并继续提供亮度和对比度。原始信号方向及有效编码上界移至画布的「采集信息」，样本名称在「结果 → 样本设置」中编辑。
- macOS 检测到新版本时在左下角显示更新按钮。接入 Beta 更新通道的 Titan 0.4.4 可通过该按钮安装 0.4.5。

macOS 安装包适用于 Apple Silicon。Windows x64 通过本页的安装包更新。发布附件附有 `SHA256SUMS.txt`。
