# Titan WB 0.1 试用说明

适用：macOS 14及以上，Apple Silicon。桌面界面为Tauri/React，计算引擎为随App内置的Python，无需另装Python或使用终端。当前是本地内部试用版，未进行Apple开发者签名公证；不宣称App Store或公开分发资格。

## 开始使用

1. 打开DMG，将Titan WB拖入应用程序目录，再打开App。
2. 首次建议点击“体验合成示例”。该示例是人工生成数据，不能作为实验结果。
3. 点击“开始定量”，应见24条测量、12条目标记录、1条饱和目标被阻止归一化、6个独立生物学单位。
4. 处理组描述性平均fold约1.994；真实WB准确性尚待用户数据验证。

## 分析自己的图像

1. 新建实验，填写名称，导入原始灰度TIFF/PNG。支持8/16位；单文件默认50MiB、25MP上限。彩色/多页需要先明确导出单通道平面。
2. 确认实际像素极性和编码上界；不能仅因文件是16位就认定ADC上界65535。未知值会保留探索性标记。
3. 选择“画条带框”，或指定目标的y区间后识别候选。添加目标和上样参考时使用对应原始泳道。候选需要人工确认身份。
4. 点击条带，在右侧编辑坐标、泳道、终点和参考；使用“建议局部背景”后检查是否含其他条带，或手动画背景框。
5. 在样本表核对每条lane对应的sample、bio、group和pair ID。技术重复映射到相同sample；不要把不同泳道自动当独立重复。
6. 核对参考对应后点击“全部标记已复核”。缺背景的条带不会变成已复核；分析内容改动后复核和结果失效。
7. 开始定量。结果页保留被阻止记录及原因，可以分别查看原测量、比值和生物学汇总。图表按终点和分析块分别显示。
8. 统计默认仅描述；选择两组Welch或配对t时明确设计、尺度和family。多膜结果不进入无批次项的普通两组检验。
9. 保存实验到新的 `.titanwb`项目文件夹；之后修改会在空闲时自动保存，也可手动保存。项目内包含原图副本。
10. 导出结果到不存在的新目录，得到CSV、JSON、PNG/SVG、ROI叠加、原图和audit校验记录。

## 跨膜与恢复

IBC模式需要每膜/终点的显式IBC以及一致pool_id；技术合并顺序为膜内技术均值→IBC桥接→同一样本膜间等权。IBC不计生物学n。分组与膜完全混杂不能解释为无混杂处理效应。

项目锁异常时，先确认旧App已关闭。“打开项目”失败提示中可使用“尝试恢复项目”；活跃的其他写入者不能被强制覆盖。manifest损坏但备份有效时恢复到新副本，保留损坏原项目。

## 当前验证边界

自动检查覆盖数学、文件、前端状态和真实Python的浏览器交互；发行包的计算引擎另做独立路径/清洁环境验证。[原生桌面验收清单](NATIVE_ACCEPTANCE.md)列出了尚需执行的步骤。macOS原生窗口的实际安装、操作验收以CP9报告为准；电脑操作权限未开放的检查不会标为通过。

没有数字饱和不代表检测链线性；勾选“实验已验证线性范围”只是记录你的实验声明。真实WB识别和定量性能须用你的原图、实验记录与人工对照完成CP10。
