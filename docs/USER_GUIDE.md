# Titan WB 0.1 操作指南

适用：macOS 14+、Apple Silicon。App 内置计算引擎，无需另装 Python。当前为本机内部试用版，未获 Apple 开发者签名与公证。

**完整流程：新建实验 → 导入原图 → 设置采集信息 → 标记目标与参考 → 添加背景 → 核对样本 → 复核 → 定量 → 保存与导出。**

## 一、先用示例熟悉界面

1. 打开 App，等待右上角显示“本地引擎就绪”。
2. 点击“体验合成示例”（侧栏也有“探索合成示例”）。
3. 点击右上角“开始定量”。
4. 在结果页切换“原始测量 / 参考归一化 / 生物学汇总”。示例应有 24 条测量、12 条目标、其中 1 条饱和目标被阻止归一化，6 个生物学单位；处理组平均相对对照约 1.994。

示例已预填样本、背景和复核关系，只用于练习，不是实验数据。

## 二、用自己的图像完成一次分析

### 1. 新建并导入

点击侧栏“新建实验”，修改上方实验名称，再点“导入图像”。可以一次选择多张图，左侧图像列表或画布上方的图像下拉框用于切换。

使用原始单通道灰度 TIFF/PNG，支持常见 8/16 位图像。单文件上限 50 MiB、2500 万像素。彩色图、多页或多通道需先明确导出需要的灰度平面；不要用截图替代原始数据。

### 2. 设置右侧“采集信息”

| 字段 | 怎样填写 |
|---|---|
| 像素极性 | 黑条带、白背景选“暗条带 / 亮背景”；白条带、黑背景选“亮条带 / 暗背景” |
| 有效编码上界 | 根据采集/导出记录填写，不能仅凭“16 位”认定为 65535；未知时留空会保留编码范围未知标记，暗条带分析必须提供上界 |
| 曝光记录 | 可记录如 5 s，供追溯 |
| 实验已验证线性范围 | 只有做过相应实验验证才勾选；App 不会替你证明线性 |

图像预览会单独拉伸亮度，定量使用原始像素。

### 3. 标记目标蛋白

首次使用建议手动画框：

1. 在右侧“新建条带与候选识别”区域，将“蛋白 / 测量名称”填为目标名，如 AKT；“条带角色”选“目标蛋白”。这两个选项也用于手动画框。
2. “手动画框对应泳道”首次选“新建泳道与样本”。
3. 点击工具栏“画条带框”，拖动鼠标框住第一条目标条带，生成 L1。
4. 继续画后续泳道，每次新建会生成新的泳道和样本草稿。
5. 点击“选择 / 移动”调整框位置；选中后拖右下角调整大小，也可在“区域编辑”填写 x0、y0、x1、y1。坐标始终对应原图，缩放不会改变坐标。

也可以使用自动候选：填写目标所在的“区域 y 起点 / 终点”（原图像素坐标），点击“识别此区域条带”。这会在该水平区域内建议条带，泳道和身份只是草稿，必须人工核对；已有同泳道/终点/角色的框不会重复添加。

### 4. 标记内参或总蛋白

将右侧“条带角色”改为“上样参考 / 总蛋白”，填写参考名称，如 GAPDH。

**手动画参考时，“手动画框对应泳道”应选已有的 L1、L2……，再画对应参考框。** 不要把 L1 的目标和它的参考建成两个不同泳道，否则无法匹配。目标和参考可以在不同图像，但必须使用同一原始泳道身份。

若使用候选识别生成参考，要逐项核对泳道是否与目标一致。角色选错时，可在所选条带的“区域编辑”中修改角色，再检查参考对应关系。

### 5. 给每个目标和参考添加背景

1. 点击条带框，或左侧对应的条带列表。
2. 点击右侧“建议局部背景”，检查上下背景框是否包含其他条带、污点或边缘。
3. 不合适时点“清空背景”，选“画背景框”，在该条带附近的空白处手画背景。
4. 对所有目标和参考重复操作。

背景不能与它的条带框重叠。缺少背景的条带不会被标记为已复核。净信号按“条带积分 − 条带面积 × 背景并集均值”计算，负值会保留。

### 6. 在“样本与分析设置”核对实验关系

先检查上方样本表：

| 字段 | 含义与用法 |
|---|---|
| 泳道 | 原始泳道身份，如 L1；目标与参考须一致 |
| 膜编号 | 同一张膜用同一编号，如 M1；不同膜用不同编号 |
| 样本 ID | 同一样本的技术重复泳道，在下拉框选择同一个样本 ID |
| 生物学 ID | 独立生物学重复使用不同 ID；共享样本 ID 的修改会同步 |
| 组别 | 如 control、treated，拼写保持一致；初始草稿默认都是 control，必须修改 |
| 配对 ID | 仅真实配对设计填写，同一对的两组使用相同 ID；非配对留空 |
| 类型 / pool | 普通样本选“生物学样本”；IBC 桥接才使用“IBC参考池”及 pool_id |

例如 2 个对照、2 个处理的独立样本，可设 L1/S1/B1/control，L2/S2/B2/control，L3/S3/B3/treated，L4/S4/B4/treated。若 L2 实际是 L1 的技术重复，应将 L2 的样本下拉框改选 S1，而不是增加独立 n。

再检查下方“目标与上样参考”：为每条目标选择同泳道的参考。普通单膜实验在“归一化设置”中保留“按膜分别分析”，并确认“对照组名称”与样本表的组名完全一致。

### 7. 复核并定量

全部检查完成后点击“确认并复核全部”，或回到图像页点击“全部标记已复核”，然后点“开始定量”。

**改实验名称保留复核与计算结果。修改框、背景、图像极性或编码上界、样本身份等，只有相关条带与依赖它的目标需要重新复核；其他条带保留复核。归一化和统计设置改变只需重新计算。撤销不会恢复已经失效的复核。** “全部复核”代表操作者确认，不代表程序验证了蛋白身份或实验设计。

### 8. 阅读结果与处理异常

| 结果位置 | 查看内容 |
|---|---|
| 原始测量 | 原积分、背景均值、净积分、饱和比例及状态；包含目标和参考 |
| 参考归一化 | 目标/参考比值及质量标记；无效项显示“—”，没有自动补值 |
| 生物学汇总 | 技术重复汇总后的数值、相对对照 fold、技术数 |
| 相对信号分布 | 选择终点与分析块；每个点代表生物学单位，不是每条泳道 |

常见问题：

- **待复核**：返回前两页检查后重新复核。
- **缺少参考 / 参考泳道不匹配**：检查参考角色、泳道和目标引用。
- **像素端点饱和**：检查原图与编码上界，必要时改用有效的低曝光原图；程序不能恢复饱和信息。
- **净信号非正**：检查条带和背景选择；App 不会强行改成正值。
- **线性范围未验证 / 编码范围未知**：结果保留探索性标记，需要补充采集或实验依据。

饱和、非正净信号或参考、未复核等情况会阻止相应归一化，但原始记录仍保留。

### 9. 如需统计，先明确比较

计算前，在“样本与分析设置”页下方“预先指定统计比较”点击“添加比较”，选择两组及检验：

- “仅描述”：默认，不计算推断检验。
- “独立组 Welch t”：两组为不同的独立生物学单位。
- “配对 t”：有完整且明确的配对 ID。

选择“原始归一化值”或“log2 归一化值”；同一比较 family 使用 Holm 校正。设置变化后直接重新计算，无需重新复核图像。检验使用生物学单位的归一化值，不使用人为恒为 1 的对照点。首版多膜结果仅作描述，不进行忽略膜批次的普通两组 t 检验。

### 10. 保存与导出

- **继续以后编辑**：点击“保存实验”，保存为新的 `.titanwb` 项目文件夹。项目内含原图副本；首次保存后，修改会在空闲时自动保存，也可以手动保存。关闭前检查底部是否仍显示未保存修改。
- **输出分析结果**：当前版本计算完成后点“导出结果”，选择一个尚不存在的新目录。导出包含测量/归一化/生物学汇总/统计 CSV、分析与项目 JSON、PNG/SVG 图、原图、ROI 叠加和 audit 校验记录。
- **下次继续**：点击“打开项目”，选择整个 `.titanwb` 文件夹。需要结果时重新计算。

保存项目和导出结果是两个不同操作；建议两者都做。

## 三、批量编辑、追溯与显示

- **条带批选**：勾选左侧条带，或 Shift + 点击画布上的框；右侧“批量调整”支持复制到新泳道、统一尺寸、移动、连续编号和背景候选。复制使用新样本草稿，不继承参考与复核，必须移动并核对身份。统一尺寸会清空旧背景。移动会连同背景一起移动；任何区域越界时，整批不应用。连续编号按所选条带从左到右排列，同步该泳道在其他图像中的条带；与未选泳道编号冲突时不应用。
- **背景候选**：建议框会避开已标记条带，但仍要人工检查污点、未标记信号和图像边缘。无合适位置时仍显示缺少背景。
- **参考匹配**：“样本与分析设置”中点击“按泳道匹配参考”，只填充同泳道唯一候选，不覆盖已有选择；多候选或无候选须手动指定。
- **样本表粘贴**：展开“从 Excel 粘贴样本表”，按六列粘贴：`泳道、样本ID、生物学ID、组别、配对ID、膜编号`。支持首行中文表头；配对ID可为空。重复/未知泳道、必填值缺失、同一样本信息冲突会拒绝整批。新样本ID创建普通生物学样本，IBC类型须另行确认。组别批量填写会同步到同一样本关联的其他泳道。
- **问题定位**：展开“质量问题与提示”，点击条目回到原图并选中条带。计算前检查背景、参考、复核；计算后补充像素检查。
- **结果追溯**：结果表中的泳道/样本链接返回 ROI；点击生物学散点或生物学ID，查看贡献条带与参考，再定位原图。统计结果显示效应量、95% CI（适用时）和校正前后 p 值。
- **画布与字号**：支持适合窗口、放大、缩小和平移。选中条带并聚焦画布后，方向键按原图 1 px 移动，Shift + 方向键为 10 px。Cmd/Ctrl+Z 撤销，Shift+Cmd/Ctrl+Z 重做；输入框内保留文字编辑快捷键。右上角可选择标准/大字号，设置会保留。

## 四、跨膜与项目恢复

IBC 模式需要每膜/终点明确指定 IBC，参考池 pool_id 一致。合并顺序为膜内技术均值→IBC 桥接→同一样本膜间等权，IBC 不计生物学 n。分组与膜完全混杂时不能解释为无混杂处理效应。首次练习建议先完成单膜流程。

项目锁异常时先确认旧 App 已关闭。“打开项目”失败提示中可点击“尝试恢复项目”；活跃的其他写入者不能被覆盖。manifest 损坏但备份有效时会恢复到新副本，保留原损坏项目。

## 当前验证范围

自动测试和安装包内置引擎的独立路径测试已经执行；原生窗口操作验收仍以 [CP 报告](checkpoints.md)为准。真实 WB 的识别、定量准确性尚需你的原图、实验映射与人工参照验证。见[原生桌面验收清单](NATIVE_ACCEPTANCE.md)。

## 强度曲线与背景检查

在左侧列表或原图中选择一个条带，展开图像下方的「强度与背景」。横轴为原图 y 坐标；曲线为该条带 x 范围内每一行的平均信号，覆盖整张图像高度。浅蓝阴影表示选中 ROI 的 y 范围，橙色虚线表示所画局部背景框并集的平均值。暗条带按明确填写的编码上界转换；预览拉伸不参与计算。

勾选「显示扣背景曲线」可以检查扣除后的正负信号。下方显示原始像素总和、背景均值和扣背景积分；后者与正式定量使用同一算法，并保留负值。没有背景、背景与 ROI 重叠或原图被修改时，会显示提示，不伪造有效结果。长图的曲线为显示而降采样并保留桶内极值，积分仍使用全部原始像素。切换条带或修改输入后会重新读取；此面板不会自动复核条带，也不会替代「开始定量」。

## 识别候选确认

1. 在「新建条带与候选识别」中填写名称、角色及 y 范围，点击「识别此区域条带」。
2. 原图以蓝色虚线展示临时候选；图像下方显示「识别候选预览」。此时项目尚未新增条带。
3. 取消勾选不需要的候选。列表显示草稿泳道对应，取消前面的候选不会使后面的候选向前错配。
4. 点击「加入所选候选」，或点击「丢弃候选」全部取消。同泳道已有同名称和角色的条带会跳过，状态消息显示数量。
5. 加入后检查区域、泳道和样本，补充背景并复核；可通过撤销回退整个加入操作。项目发生编辑后，旧候选会自动失效，需要重新识别。

## 导出预览

完成当前版本定量后，点击右上方「导出结果」。弹窗显示由实际导出引擎绘制的 PNG，可调整每面板宽度（3–8 英寸）、图表高度（3–8 英寸）、字号（8–24 pt）及 DPI（72–300）。多个分析面板横向排列，整图宽度随面板数增加；超过 2000 万像素时需降低尺寸或 DPI。

修改设置后等待新预览生成，再点击「选择目录并导出」。预览只在屏幕中缩放，像素尺寸显示在下方。导出仍含 PNG、SVG、CSV、原图、标注及审计；绘图设置记录在 audit.json 中。关闭弹窗不会更改实验数据，已有目录不会被覆盖。预览界面与正式导出使用相同绘图函数和设置。
