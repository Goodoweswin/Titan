# Titan WB 操作指南

适用：macOS 14+、Apple Silicon。App 内置计算引擎，无需另装 Python。当前为本机内部试用版，未获 Apple 开发者签名与公证。

**默认流程：新建实验 → 导入内参 → 确认泳道与内参 → 逐个添加目标 → 查看归一化结果 → 保存与导出。**

点击左栏「Western blot」回到模块首页。点「继续当前实验」可回到原视图和未确认的组图草稿。首页和引导工作区提供「图像操作指引」。

## 项目、分析与图表左栏

左栏用于项目、分析和已保存图表的导航。统计数据表、图形快照和 IF 视野在右侧工作区选择。拖动左栏右边缘可以调整宽度，双击恢复默认。

工作区跟随系统的浅色或深色外观，系统切换后立即生效。WB、IF、统计表格和弹窗共用夜间配色；原始图像、荧光通道颜色和论文图的输出配色保持原样。

- **新建项目：**在首页点「新建项目」，或在左栏「项目」右侧的「＋」菜单中创建。点击项目名称打开项目主页；旁边的箭头只展开或收起分析列表。
- **添加资料：**在项目主页点「添加资料」。Titan 保存所选文件的副本，原件可以移动或删除。勾选资料并选择 WB、IF 或统计与绘图，可直接在此项目中开始分析。
- **新建分析：**左栏「新建分析」默认独立保存；从项目主页开始时默认属于该项目，创建时可以修改。也可进入左栏的 WB、IF 或统计工具页直接导入，成功导入后会创建独立分析，取消不留下空记录。工具页之间切换不会改变项目资料。
- **更改归属：**在分析的「⋯」菜单中点「移到项目」或「移出项目」。分析及其图表、结果会随列表归属显示；原分析文件和项目资料保留。移出整个项目列表时，里面的分析转到「独立分析」，此电脑上的资料副本仍保留。
- **搬到另一台电脑：**在项目主页点「导出项目包」，将整个 `.titanproject` 文件夹复制到目标电脑，再从左栏「＋ → 打开项目包」导入。项目包包含资料副本、已保存的分析和图表、已登记且可验证的导出文件。导入会创建新的项目副本。包内统计来源重新关联；未随包携带的来源保留当时的统计数据与结果，无法直接更新来源。
- **打开旧分析：**在左栏「＋ → 打开已有分析」选择 `.titanwb`、`.titanif` 或 `.titanstats` 文件夹。首次登记的外部分析在「独立分析」中显示。重新打开已登记的分析时会回到上次的工作台、结果或组图。

项目的「图表与导出」汇总已保存的图和已登记的输出。点击图可打开对应版本；点击外部导出可打开对应文件。文件移走后仍有缺失提示。

分析创建后自动保存，顶部可改名并查看保存状态。WB 的双页图标是「另存副本」，会复制原图和版本历史；初始归属与来源相同。旧格式升级时需另存，原文件保留。

在 WB 或 IF 结果页选择发送到统计，新分析默认归入来源分析的项目，也可改为独立分析或其他项目。统计表保留来源追溯；原分析移位后，先在左栏重新定位，再从统计页返回或更新来源。历史统计导出保留选中的数据和运行版本。

顶部使用无编号的视图导航。导入原图、开始定量、结果导出按当前视图显示；WB 组图页顶部的导入图标也能补充原图，不必放弃组图草稿。WB 文档自身的“保存组图”“导出组图”位于组图工具栏。右上角可切换标准/大字号。

结果页首次生成的正式图、手动保存的变体和成功导出的图可从左栏找回。打开图表时使用生成时冻结的数据；调整样式保存为新版本，“另存新图”保留另一份文档。当前数据改变后，旧图提示源已变化；只有点击“用当前分析更新源数据”才替换数据源，旧版本继续保留。未保存的样式草稿切换时会提示；普通预览不会不断产生历史记录。

## 论文柱图与独立多组统计

在“结果”页展开“图形设置”：选择“均值柱 + 原始点”“均值柱”或“散点 + 均值”，自由选择各组颜色（含HEX）、SD/SEM/95%CI。展开“文字、坐标与图形细节”可改标题、组名、顺序、轴范围/刻度、字号、点形、空心、柱宽、间距和线宽。“应用样式到项目”保存默认样式；“保存当前图表”记录正式版本。所有样式均不更改原像素、ROI或复核。

先在“样本信息、分组与统计”核对独立生物学ID/分组并确认设计，再展开“统计分析与方法说明”，点击“添加多组分析”。仅支持单因素、单分析膜、三个及以上独立组：

- 普通单因素ANOVA假定等方差；“各处理组与对照”采用Dunnett，“所有组两两”采用Tukey（不等n为Tukey–Kramer）。
- Welch ANOVA允许方差不等；后续使用Games–Howell。即使只显示与对照比较，校正家族仍包括全部所选组两两比较。它与Dunnett T3不同。
- 默认“仅描述”。根据预定问题、实验设计和分布假设选择方法，不按p更小自动选择。跨膜批次、重复测量或多因素设计不能直接套用这个入口。每组至少2个有效独立单位才计算，不代表n=2具有充分功效或能验证分布假设。

技术泳道不增加独立n。SD显示个体离散；SEM=SD/√n和均值t区间反映均值精度，n<2不生成误差线。图上每组均值CI与组对的同时95%CI不同。统计使用目标/内参归一化值，可明确选择log2（仅正值）；图上的相对对照倍数是独立显示选项，不传播估计对照均值的不确定性。总体p和组对调整p分别报告；在“比较标记与p值”选择已计算组对，不能用总体p替代某对差异。

多组校正以每个比较设置×蛋白×分析膜为家族，不自动跨蛋白校正。原两组Welch/配对t与显式Holm家族保留。方法说明参考[GraphPad的Tukey与Dunnett解释](https://www.graphpad.com/guides/prism/latest/statistics/stat_the_methods_of_tukey_and_dunne.htm)及[SciPy Games–Howell接口](https://docs.scipy.org/doc/scipy-1.17.1/reference/generated/scipy.stats.tukey_hsd.html)。Titan不是Prism的完整统计功能实现。

## 0.2 默认流程：内参 → 目标 → 结果

分析流程保留“内参 → 目标 → 结果”三个视图，另有可独立进入的“WB 组图”。旧版的逐条手画方式保留在“手动调整与图像信息 → 打开手动条带编辑”；下文原有手动操作说明供这一入口使用。

1. 新建实验，导入内参原图。多页 TIFF 可预览并选择页；灰度调色板和 16 位灰度均保留原始数值。“显示反色”只改变画面，原始信号方向参与计算，两者独立。
2. 在“内参”页点击“选择区域”，拖选内参所在的横向区域，尽量避开 marker。点“识别泳道”，检查蓝色泳道边界、绿色峰区与虚线背景。预计泳道数可留空；数量不合适时手动指定后重试。
3. 点击泳道可查看曲线、填写样本名称；可拖动泳道及宽度，调整峰区或画局部背景。选中误识别的 marker 后可“排除选中泳道”。弱信号位置标为待检查；多峰必须选择要测量的峰。确认后点“确认内参”。
4. 在“目标”页填写蛋白名称，选图或同一图像的另一处区域，点“识别目标”。系统沿用已确认的泳道与样本；不同裁剪图有偏移时，先查看建议，再用“移动整组”、单泳道边界或高级设置中的间距调整对齐。
5. 检查峰区、背景和未检出的泳道后，点“确认目标”。添加下一个目标不必重填样本。未检出保留原泳道空位，不补位、不自动计为 0。
6. “结果”页自动更新每泳道/样本的目标净积分、内参净积分与比值。没有有效内参、未确认或存在饱和等问题时不输出有效比值，按提示处理。默认不把泳道数当作生物学 n；需要组间统计时，展开“样本信息、分组与统计”，明确重复/分组后确认实验设计。
7. 新实验已自动保存在本机项目库，保存实验与导出结果分别操作。升级旧项目首次保存时选择新的 `.titanwb` 副本；旧文件不被覆盖。结果页下方直接显示当前图表，点“导出 Excel 与图表”可预览并调整尺寸/字号。导出含 `results.xlsx`、`plot.png`/`plot.svg`、`lanes.csv`（包括缺失状态）、其他 CSV、原图、页码、布局、ROI/背景、分析结果和审计文件；没有生物学汇总时，图表按泳道展示比值。

重新识别内参会沿用已确认的泳道身份；位置变化时拖动蓝框对齐，不重新按距离猜测样本。手动条带编辑可修改峰区、背景或删除条带；集合内的名称、角色、泳道和内参对应在简洁流程中修改。删除后保留待确认槽位，可重新识别恢复。

主画面每次只有一个主要动作；算法参数和元数据按需展开。仅看画面黑白方向不能判断原始信号极性；需要暗信号计算时，按采集记录补全有效编码上界。所有正式积分仍使用确认区域内的原始像素及局部背景并集。

### 内参确认后的目标蛋白操作

1. 点“添加目标”，填蛋白名称。不同文件点“导入目标图像”，导入后自动显示新图；同一张图上的另一种蛋白无需重复导入。
2. 如图像倾斜，先“旋转校正”，再框选目标区域。旋转页有固定在画面上的水平、垂直参考线，可拖到条带旁比对，也可用方向键移动、居中或隐藏；参考线不随图像转动。
3. 点“识别目标”先复用内参模板。同图保留横向坐标，不同裁剪图按内参、目标的所选区域适配。样本编号沿用内参，泳道高度限于当前目标区域，左右手柄与方向键调整、移动整组、峰区、背景和撤销与内参一致。
4. 位置明显不合适时，可点“重新识别泳道位置”。程序在目标图中建议位置，必须逐一指定对应的原泳道后确认，未检出的位置仍保留；数量不符时调整区域，或点“沿用内参位置”后手动调整。不要把缺失条带后的泳道向前补位。
5. 检查峰区、背景及缺失状态，点“确认目标”；再添加下一个目标。重新框选区域后，重新识别使用新区域并保留已调好的横向位置。切换对应内参后需要重新识别并确认，才更新归一化引用。

### 泳道微调、撤销与图像校正

- “选择区域”只用于拖选蛋白所在区域。“调整泳道”只操作单个泳道，拖动空白处不会重画区域；点 L1、L2 等或直接点框可选中泳道。
- 在“调整泳道”下，拖动蓝框或其中的绿框均可左右平移该泳道；两侧小手柄分别调整左、右边界。点击画布后，←/→ 每次移动 1 个原图坐标像素，Shift＋方向键每次移动 10 像素；边界受分析区域与相邻泳道限制。
- 已确认的内参、目标可以直接调整，会先进入草稿；其他泳道的峰区与背景保留。检查后再次确认才加入实验。“重新识别”则重新生成整组峰区建议。
- 顶部撤销/重做优先回退画布中未确认的区域、泳道、峰区、背景和候选选择。Mac 用 ⌘Z / ⇧⌘Z，Windows 用 Ctrl+Z / Ctrl+Shift+Z。确认一次修改后，它作为一个实验操作进入撤销记录。识别中撤销会丢弃迟到结果；重做会重新执行尚未完成的识别。输入框中的快捷键仍编辑文字。
- 图像倾斜时点“旋转校正”：可左右旋转 90°，也可用角度输入或滑块微调。应用后保留原图并增加校正视图，需要重新框选；在图像下拉框可切回原图。替换已经确认的内参图像时，必须逐个指定新候选对应哪个原泳道，程序不会按距离猜测样本身份。
- 校正视图与识别使用插值预览；定量按校正选框覆盖的原始像素中心计数与积分，不用插值后的亮度。小角度下像素数量可能与矩形宽×高不同，背景取原始像素的并集，旋转空白边缘不参与计数。原图 hash、页码、角度及选框保存在项目和导出审计信息中。

## WB 条带组图

打开实验后，点击顶部 **WB 组图 → 新建组图**。此功能免费、本地运行，不要求先完成定量，也不与统计柱图拼成整版论文图。

1. 如果已经设置蛋白，按目标蛋白、内参生成候选行；否则从导入的原图开始。每行均需人工确认裁剪。
2. 在原图上拖动，框选包含多个泳道的连续横向区域；也可以输入 X0、Y0、X1、Y1 像素坐标。坐标对应当前旋转校正后的原图，右、下边界不包含在裁剪中。
3. 填写蛋白名，点击“确认本行裁剪”。右侧原图下拉框和＋可添加其他蛋白行，箭头可调整行顺序。
4. “预期分子量”是手动文字标注，不是软件测量结果。“Marker 标注”按实际 marker 填写分子量与其在校正后原图中的 Y 坐标；修改裁剪后，超出范围的 marker 会报错，需重新核对。
5. 添加顶部样本或处理条件标签，按图像区宽度的百分比调整横向位置。已有清楚一致的泳道映射时可以带入标签；样本顺序或位置不同则需手动核对。
6. 默认白底、左蛋白名、右 kDa，85 mm 宽、8 pt 字、3 mm 行间距。可以调整总宽、图像区宽度、字号、间距、300/600 DPI；图像区宽度 0 表示自动。保持原始宽高比，不局部拉伸泳道。
7. 点击“保存组图”保留可继续编辑的文档。一个实验可保存多份组图，通过“已保存的组图”下拉框重开；修改组图不会改变定量 ROI 或分析结果。撤销/重做只作用于当前组图。
8. 等待新预览生成，点击“导出组图”，选择一个尚不存在的新文件夹。得到 `figure.png`、含嵌入位图和可编辑文字的 `figure.svg`、记录图源哈希/页号/旋转/裁剪/标签的 `source.json`。SVG 可在矢量编辑器中继续精调；原图和编辑历史随整个 `.titanwb` 项目保存。

提高导出 DPI 不会增加原图细节；预览下方显示按最终物理尺寸计算的原图有效分辨率。合成项目的组图保留“非实验数据”标识。恢复默认版式只重置样式，保留裁剪、行顺序和文字。离开有未保存修改的组图时，取消切换可返回保存。

每行来自一块连续原图区，不支持切出单个泳道重新拼接或修补条带。当前组图功能通过合成数据和浏览器流程检查；真实 WB 的最终裁剪、分子量位置及投稿要求仍需使用者核对。

## Excel、图表与导出

完成目标确认后，在“结果”查看泳道表和图。点击“导出 Excel 与图表”（右上角“导出结果”也可），等待实际图表预览，按需调整尺寸、字号、DPI，再点“选择目录并导出”，指定一个尚不存在的新目录。

- `results.xlsx`：说明、泳道结果、原始测量、参考归一化、生物学汇总、统计结果、分组描述、多组总体检验、多重比较、样本信息、图像来源和图表，共12个工作表。数值单元格保留原始计算精度；显示格式不改变数值。表头可筛选、首行冻结。
- Excel 的图表页嵌入与 `plot.png` 相同的图片；可编辑数值表，图形不是 Excel 原生可编辑图表。PNG 适合粘贴，SVG 适合矢量排版。
- 未检出的数值留空，状态列注明原因。逐泳道图保留相应位置，ND 表示未检出，NA 表示当前不可计算；二者都不是 0。
- 尚未确认生物学设计时，默认显示逐泳道比值；生物学汇总/统计表可能只有表头。需要组间图与统计时，在“样本信息、分组与统计”确认真实重复关系。
- 同一目录还保留 CSV、JSON、原图、标注与审计哈希。修改原始输入后，需等待新结果和新预览，不能导出旧版本。

## 一、先用示例熟悉界面

1. 打开 App，等待右上角显示“本地引擎就绪”。
2. 点击“体验合成示例”（侧栏也有“探索合成示例”）。
3. 点击右上角“开始定量”。
4. 在结果页切换“原始测量 / 参考归一化 / 生物学汇总”。示例应有 24 条测量、12 条目标、其中 1 条饱和目标被阻止归一化，6 个生物学单位；处理组平均相对对照约 1.994。

示例已预填样本、背景和复核关系，只用于练习，不是实验数据。

## 二、用自己的图像完成一次分析

### 1. 新建并导入

点击侧栏“新建实验”，修改上方实验名称，再点“导入图像”。可以一次选择多张图，左侧图像列表或画布上方的图像下拉框用于切换。

使用原始单通道灰度 TIFF/PNG，支持常见 8/16 位图像。单文件上限 50 MiB，每页上限 2500 万像素；不要用截图替代原始数据。

多页 TIFF 会打开“选择 TIFF 页面”：点击整张页面卡片选中或取消，同时查看预览。左侧方框仅显示选中状态，选好的卡片带高亮边框；也可“全选可用页”，再点“导入所选页面”。用 Tab 聚焦卡片后，可按空格或 Enter 切换选择。每页成为独立图像，名称标明“第 N 页”。“跳过此文件”或 Esc 不导入该文件。彩色调色板、RGB 或多通道页会显示原因并禁止勾选（R/G/B LUT 相同的灰度调色板可用），同文件中的合格灰度页仍可导入。不同页可能对应不同曝光或通道，需核对采集记录，不能因预览亮度相近就视为同一条件。

保存项目时保留整个原始 TIFF 和所选页码；重开、定量及导出均读取对应页的原始像素。预览亮度拉伸不改变定量数据。

### 2. 设置右侧“采集信息”

| 字段 | 怎样填写 |
|---|---|
| 像素极性 | 黑条带、白背景选“暗条带 / 亮背景”；白条带、黑背景选“亮条带 / 暗背景” |
| 有效编码上界 | 根据采集/导出记录填写，不能仅凭“16 位”认定为 65535；未知时留空会保留编码范围未知标记，暗条带分析必须提供上界 |
| 曝光记录 | 可记录如 5 s，供追溯 |
| 实验已验证线性范围 | 只有做过相应实验验证才勾选；App 不会替你证明线性 |

图像预览会单独拉伸亮度，定量使用原始像素。

### 3. 标记目标蛋白

首次使用建议手动画框：

1. 在右侧“新建条带与候选识别”区域，将“蛋白 / 测量名称”填为目标名，如 AKT；“条带角色”选“目标蛋白”。这两个选项也用于手动画框。
2. “手动画框对应泳道”首次选“新建泳道与样本”。
3. 点击工具栏“画条带框”，拖动鼠标框住第一条目标条带，生成 L1。
4. 继续画后续泳道，每次新建会生成新的泳道和样本草稿。
5. 点击“选择 / 移动”调整框位置；选中后拖右下角调整大小，也可在“区域编辑”填写 x0、y0、x1、y1。坐标始终对应原图，缩放不会改变坐标。

也可以使用自动候选：填写目标所在的“区域 y 起点 / 终点”（原图像素坐标），点击“识别此区域条带”。这会在该水平区域内建议条带，泳道和身份只是草稿，必须人工核对；已有同泳道/终点/角色的框不会重复添加。

### 4. 标记内参或总蛋白

将右侧“条带角色”改为“上样参考 / 总蛋白”，填写参考名称，如 GAPDH。

**手动画参考时，“手动画框对应泳道”应选已有的 L1、L2……，再画对应参考框。** 不要把 L1 的目标和它的参考建成两个不同泳道，否则无法匹配。目标和参考可以在不同图像，但必须使用同一原始泳道身份。

若使用候选识别生成参考，要逐项核对泳道是否与目标一致。角色选错时，可在所选条带的“区域编辑”中修改角色，再检查参考对应关系。

### 5. 给每个目标和参考添加背景

1. 点击条带框，或左侧对应的条带列表。
2. 点击右侧“建议局部背景”，检查上下背景框是否包含其他条带、污点或边缘。
3. 不合适时点“清空背景”，选“画背景框”，在该条带附近的空白处手画背景。
4. 对所有目标和参考重复操作。

背景不能与它的条带框重叠。缺少背景的条带不会被标记为已复核。净信号按“条带积分 − 条带面积 × 背景并集均值”计算，负值会保留。

### 6. 在“样本与分析设置”核对实验关系

先检查上方样本表：

| 字段 | 含义与用法 |
|---|---|
| 泳道 | 原始泳道身份，如 L1；目标与参考须一致 |
| 膜编号 | 同一张膜用同一编号，如 M1；不同膜用不同编号 |
| 样本 ID | 同一样本的技术重复泳道，在下拉框选择同一个样本 ID |
| 生物学 ID | 独立生物学重复使用不同 ID；共享样本 ID 的修改会同步 |
| 组别 | 如 control、treated，拼写保持一致；初始草稿默认都是 control，必须修改 |
| 配对 ID | 仅真实配对设计填写，同一对的两组使用相同 ID；非配对留空 |
| 类型 / pool | 普通样本选“生物学样本”；IBC 桥接才使用“IBC参考池”及 pool_id |

例如 2 个对照、2 个处理的独立样本，可设 L1/S1/B1/control，L2/S2/B2/control，L3/S3/B3/treated，L4/S4/B4/treated。若 L2 实际是 L1 的技术重复，应将 L2 的样本下拉框改选 S1，而不是增加独立 n。

再检查下方“目标与上样参考”：为每条目标选择同泳道的参考。普通单膜实验在“归一化设置”中保留“按膜分别分析”，并确认“对照组名称”与样本表的组名完全一致。

### 7. 复核并定量

全部检查完成后点击“确认并复核全部”，或回到图像页点击“全部标记已复核”，然后点“开始定量”。

**改实验名称保留复核与计算结果。修改框、背景、图像极性或编码上界、样本身份等，只有相关条带与依赖它的目标需要重新复核；其他条带保留复核。归一化和统计设置改变只需重新计算。撤销不会恢复已经失效的复核。** “全部复核”代表操作者确认，不代表程序验证了蛋白身份或实验设计。

### 8. 阅读结果与处理异常

| 结果位置 | 查看内容 |
|---|---|
| 原始测量 | 原积分、背景均值、净积分、饱和比例及状态；包含目标和参考 |
| 参考归一化 | 目标/参考比值及质量标记；无效项显示“—”，没有自动补值 |
| 生物学汇总 | 技术重复汇总后的数值、相对对照 fold、技术数 |
| 相对信号分布 | 选择终点与分析块；每个点代表生物学单位，不是每条泳道 |

常见问题：

- **待复核**：返回前两页检查后重新复核。
- **缺少参考 / 参考泳道不匹配**：检查参考角色、泳道和目标引用。
- **像素端点饱和**：检查原图与编码上界，必要时改用有效的低曝光原图；程序不能恢复饱和信息。
- **净信号非正**：检查条带和背景选择；App 不会强行改成正值。
- **线性范围未验证 / 编码范围未知**：结果保留探索性标记，需要补充采集或实验依据。

饱和、非正净信号或参考、未复核等情况会阻止相应归一化，但原始记录仍保留。

### 9. 如需统计，先明确比较

计算前，在“样本与分析设置”页下方“预先指定统计比较”点击“添加比较”，选择两组及检验：

- “仅描述”：默认，不计算推断检验。
- “独立组 Welch t”：两组为不同的独立生物学单位。
- “配对 t”：有完整且明确的配对 ID。

选择“原始归一化值”或“log2 归一化值”；同一比较 family 使用 Holm 校正。设置变化后直接重新计算，无需重新复核图像。检验使用生物学单位的归一化值，不使用人为恒为 1 的对照点。首版多膜结果仅作描述，不进行忽略膜批次的普通两组 t 检验。

### 10. 保存与导出

- **继续以后编辑**：新实验立即自动保存在本机项目库。点击“保存实验”立即保存；“另存副本”选择新的 `.titanwb` 文件夹。项目内含原图与图表历史。关闭时先完成保存；失败则留在应用中。
- **输出分析结果**：当前版本计算完成后点“导出结果”，选择一个尚不存在的新目录。导出包含测量/归一化/生物学汇总/统计 CSV、分析与项目 JSON、PNG/SVG 图、原图、ROI 叠加和 audit 校验记录。
- **下次继续**：点击“打开项目”，选择整个 `.titanwb` 文件夹。需要结果时重新计算。

保存项目和导出结果是两个不同操作；建议两者都做。

## 三、批量编辑、追溯与显示

- **条带批选**：勾选左侧条带，或 Shift + 点击画布上的框；右侧“批量调整”支持复制到新泳道、统一尺寸、移动、连续编号和背景候选。复制使用新样本草稿，不继承参考与复核，必须移动并核对身份。统一尺寸会清空旧背景。移动会连同背景一起移动；任何区域越界时，整批不应用。连续编号按所选条带从左到右排列，同步该泳道在其他图像中的条带；与未选泳道编号冲突时不应用。
- **背景候选**：建议框会避开已标记条带，但仍要人工检查污点、未标记信号和图像边缘。无合适位置时仍显示缺少背景。
- **参考匹配**：“样本与分析设置”中点击“按泳道匹配参考”，只填充同泳道唯一候选，不覆盖已有选择；多候选或无候选须手动指定。
- **样本表粘贴**：展开“从 Excel 粘贴样本表”，按六列粘贴：`泳道、样本ID、生物学ID、组别、配对ID、膜编号`。支持首行中文表头；配对ID可为空。重复/未知泳道、必填值缺失、同一样本信息冲突会拒绝整批。新样本ID创建普通生物学样本，IBC类型须另行确认。组别批量填写会同步到同一样本关联的其他泳道。
- **问题定位**：展开“质量问题与提示”，点击条目回到原图并选中条带。计算前检查背景、参考、复核；计算后补充像素检查。
- **结果追溯**：结果表中的泳道/样本链接返回 ROI；点击生物学散点或生物学ID，查看贡献条带与参考，再定位原图。统计结果显示效应量、95% CI（适用时）和校正前后 p 值。
- **画布与字号**：支持适合窗口、放大、缩小和平移。选中条带并聚焦画布后，方向键按原图 1 px 移动，Shift + 方向键为 10 px。Cmd/Ctrl+Z 撤销，Shift+Cmd/Ctrl+Z 重做；输入框内保留文字编辑快捷键。右上角可选择标准/大字号，设置会保留。

## 四、跨膜与项目恢复

IBC 模式需要每膜/终点明确指定 IBC，参考池 pool_id 一致。合并顺序为膜内技术均值→IBC 桥接→同一样本膜间等权，IBC 不计生物学 n。分组与膜完全混杂时不能解释为无混杂处理效应。首次练习建议先完成单膜流程。

项目锁异常时先确认旧 App 已关闭。“打开项目”失败提示中可点击“尝试恢复项目”；活跃的其他写入者不能被覆盖。manifest 损坏但备份有效时会恢复到新副本，保留原损坏项目。

## 当前验证范围

自动测试和安装包内置引擎的独立路径测试已经执行；原生窗口操作验收仍以 [CP 报告](checkpoints.md)为准。真实 WB 的识别、定量准确性尚需你的原图、实验映射与人工参照验证。见[原生桌面验收清单](NATIVE_ACCEPTANCE.md)。

## 强度曲线与背景检查

在图像下方的条带列表或原图中选择一个条带，展开图像下方的「强度与背景」。横轴为原图 y 坐标；曲线为该条带 x 范围内每一行的平均信号，覆盖整张图像高度。浅蓝阴影表示选中 ROI 的 y 范围，橙色虚线表示所画局部背景框并集的平均值。暗条带按明确填写的编码上界转换；预览拉伸不参与计算。

勾选「显示扣背景曲线」可以检查扣除后的正负信号。下方显示原始像素总和、背景均值和扣背景积分；后者与正式定量使用同一算法，并保留负值。没有背景、背景与 ROI 重叠或原图被修改时，会显示提示，不伪造有效结果。长图的曲线为显示而降采样并保留桶内极值，积分仍使用全部原始像素。切换条带或修改输入后会重新读取；此面板不会自动复核条带，也不会替代「开始定量」。

## 识别候选确认

1. 在「新建条带与候选识别」中填写名称、角色及 y 范围，点击「识别此区域条带」。
2. 原图以蓝色虚线展示临时候选；图像下方显示「识别候选预览」。此时项目尚未新增条带。
3. 取消勾选不需要的候选。列表显示草稿泳道对应，取消前面的候选不会使后面的候选向前错配。
4. 点击「加入所选候选」，或点击「丢弃候选」全部取消。同泳道已有同名称和角色的条带会跳过，状态消息显示数量。
5. 加入后检查区域、泳道和样本，补充背景并复核；可通过撤销回退整个加入操作。项目发生编辑后，旧候选会自动失效，需要重新识别。

## 导出预览

完成当前版本定量后，点击右上方「导出结果」。弹窗显示由实际导出引擎绘制的 PNG，可调整每面板宽度（3–8 英寸）、图表高度（3–8 英寸）、字号（8–24 pt）及 DPI（72–300）。多个分析面板横向排列，整图宽度随面板数增加；超过 2000 万像素时需降低尺寸或 DPI。

修改设置后等待新预览生成，再点击「选择目录并导出」。预览只在屏幕中缩放，像素尺寸显示在下方。导出仍含 PNG、SVG、CSV、原图、标注及审计；绘图设置记录在 audit.json 中。关闭弹窗不会更改实验数据，已有目录不会被覆盖。预览界面与正式导出使用相同绘图函数和设置。

### 图像放大与移动（0.3.4）

旋转校正、泳道区域选择和 WB 条带裁剪都支持相同的视图操作：

- 滚轮以鼠标位置为中心放大/缩小，也可点击放大、缩小按钮。
- 点击“移动视图”后拖动，或在画布聚焦时按住空格拖动、使用鼠标中键拖动。把边缘条带移到中间后，再点一次“移动视图”退出并框选；泳道画布也可点击“选择区域”退出移动模式。
- 点击“查看全图”或“适合窗口”恢复视图。在画布聚焦时也可用 +、−、0 缩放和恢复。
- 旋转校正中的参考线保持水平/垂直，可单独拖动；放大和平移不改变旋转角度。
- 视图操作不改变原图或测量数据；缩放后框选仍映射为原图像素坐标。
