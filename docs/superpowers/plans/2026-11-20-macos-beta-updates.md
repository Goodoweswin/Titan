# Titan Mac Beta 应用内更新验收计划

**目标**是让 Apple Silicon 用户手动安装首个接入更新通道的 Beta 后，可以在 Titan 左下角点击完成后续升级。基线是 `codex/titan-integrated` 上整合了最新 WB 修改的 `e8f52c8`。正式首发候选为应用版本 `0.4.4` 和发布标签 `v0.4.4-beta.1`。

**设计依据**见 [Titan 应用内更新](../../releases/IN_APP_UPDATES.md)。沿用 Tauri v2 更新签名和现有双平台 Release workflow。GitHub Release 托管安装包，`updates` 分支的 `beta.json` 提供固定 HTTPS 地址。应用标识维持 `com.titan.wb`。

## 验收清单

| 项目 | 通过条件 |
| --- | --- |
| 检测 | 启动查询 Beta 清单。有更高版本且含 Mac ARM64 产物时，左下角显示「更新并重启」。同版本、较旧版本、离线或清单不可读时，首页可正常使用。 |
| 更新 | 点一次后完成下载、签名验证、保存、安装和自动重启。重启后核对实际 App 版本和进程。当前通道版本已安装后，更新按钮隐藏。 |
| 工作保留 | 更新前保存可保存的工作。有分析在运行或待确认的组图草稿时延后安装。重启后能打开原分析、图表和导出记录，已登录测试账号能继续使用或准确提示系统授权。 |
| 失败恢复 | 错误签名、签名版本不符或下载中断时，旧 App 保持可用。恢复正确资源后能重试。真实的第二实例仍被账户所有权锁拒绝。 |
| 发布 | Mac DMG、ZIP、签名更新归档和签名齐全，Windows x64 NSIS 同批构建。对公开附件做 SHA-256 检查，随后将清单指向已验证的 Mac 归档。 |
| 安装与记录 | 保留本机旧 App 和项目库备份。验收通过后用正式包更新本机并实际打开，登记标签、提交、产物、检测地址、签名和验收证据。Windows 应用内更新保持关闭。 |

## 执行顺序

1. [x] **应用升级回归。**核对 `src/AppUpdate.tsx` 的保存、下载和安装重试。在 `src-tauri/src/auth/client.rs` 验证短时账户所有权锁移交和持续持锁。上一次进程短时退出可恢复，持续持锁仍拒绝并发。
2. [ ] **发布流程。**在 `.github/workflows/release.yml` 为 Mac Beta 构建加载公开更新配置并生成 `.app.tar.gz` 和 `.sig`。发布的清单以打包版本为准，通过 `darwin-aarch64` 指向该标签的固定下载地址。两个平台和附件验证全部通过后才推进清单。重复执行可恢复发布，旧标签不能覆盖更新版本，推送使用正常快进。
3. [ ] **隔离原生验收。**用独立测试签名、应用标识、清单和合成项目运行旧版到新版。测试同版隐藏、无网络、坏签名和成功重试、稍后安装、一次点击重启及数据恢复。生产密钥、现装 Titan 和真实项目数据均不进入隔离夹具。
4. [x] **配置正式签名。**确认 GitHub Secrets 无既有生产密钥，生成带密码的密钥并安全留存备份。将私钥与密码分别配置为 `TAURI_SIGNING_PRIVATE_KEY` 和 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`，只让负责签名的构建步骤读取。公钥进入 Mac Beta 构建配置。从本机加密备份和钥匙串恢复签名已通过，公钥 SHA-256 为 `9f40dfeefad4d0351b05fd4b7aa1a46b0842c08005b3c98cc7e90df8e9011651`。
5. [ ] **发布和本机安装。**验证分支来源、版本一致性和回归结果，再推送正式标签。跟进 GitHub 的 Mac、Windows 和发布作业，下载核对共有附件和实时清单。备份本机后安装下载的正式包，确认能启动、已有项目可读且同版已隐藏更新按钮，更新版本注册表。

发布前用隔离构建跑通从下载到重启的完整流程。正式下载包另核对打包版本、签名、安装和清单响应。macOS 的文件或钥匙串授权根据原生验收现场记录。

当前本机磁盘余量约 2 GiB。先复用已有构建缓存和测试产物。若本机打包空间不足，改用 GitHub Actions 构建，再在本机完成原生验收。

## 隔离测试记录

Apple Silicon 原生测试用环回清单从实际 `0.4.3` 升至 `0.4.4`。无网络时可打开和保存合成 WB 分析。错误签名与签名版本不符均阻止安装，修复清单后可重新检测。下载完成后可暂缓安装。从原分析点击一次后，签名包安装，进程自动重启，并重新打开已保存的分析。隔离应用使用访客模式。线上账户恢复与原有项目访问留待正式包本机验收。
