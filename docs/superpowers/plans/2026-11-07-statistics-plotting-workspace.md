# Titan：独立统计与绘图模块实施计划

日期：2026-11-07（Asia/Shanghai）
状态：已将统计预览与 v0.4.0-beta.3 整合；已完成与仍待完善的范围见 `docs/STATS_USER_GUIDE.md`。
目标：整合当前统计、绘图、图表历史与导出能力，建立能独立接收表格数据、也能衔接 WB 和后续免疫荧光的统计与绘图工作区。

本计划依据当前工作区代码制定。它替代旧设计中“统计与图表只能位于 WB 结果页内”的未来产品约束；既有科学计算规则、项目兼容和历史图形规则继续保留。实施使用独立开发副本与独立预览应用标识，原工作区改动和用户实验保持完整。v0.4 已有免疫荧光，本次在该基础上增加并列入口。

## 1. 产品决定

1. 左侧增加与 Western blot、免疫荧光并列的“统计与绘图”入口。用户无需导入实验图像即可新建统计项目。
2. 统计和绘图属于同一个模块，内部按“数据表、分析、图形”组织；后续增加“排版”。同一张表支持多个分析和多个图形。
3. WB 负责原图测量、质量状态、归一化及独立单位汇总；通用统计引擎接收结构化数据，不要求伪造蛋白、膜或泳道。
4. 借鉴 Prism 的结构化表格、分析结果与图形联动、对象属性编辑和样式复用；沿用 Titan 中文界面、离线桌面架构与图像来源追溯。
5. 第一版交付一个可保存、重开、分析和导出的完整模块。后续按数据类型扩展统计方法，不一次堆入全部 Prism 功能。

## 3. 用户工作流程

### 3.1 独立表格入口

新建统计项目 → 新建列式数据表或导入/粘贴 → 核对分组和独立单位 → 选择分析 → 查看结果和图形 → 编辑样式 → 保存/导出。

- 首版支持手工输入、Excel 单元格粘贴、CSV/TSV、`.xlsx` 数值数据。
- `.xlsx` 先选择工作表并预览；显示解析错误、空值、非数值和公式缓存缺失。不执行公式或宏，不将日期当成普通测量值。
- 导入支持“每列一组”的宽表，以及通过映射指定组别/数值/样本 ID 的长表。
- 表格支持矩形粘贴、增删行列、撤销/重做、重命名、组顺序和可追溯排除。配对必须有明确 ID；排序不能改变配对关系。
- 初始仅展示描述统计；正式推断前确认独立单位及设计。可录入已经聚合的独立值，也可记录技术重复并显式选择汇总规则。
- 首版输入以原始观测值为主；仅均值、误差和 n 的汇总数据作为后续独立输入类型，不能伪造散点。

### 3.2 WB 入口

WB 完成定量 → “发送到统计与绘图” → 选择终点/分析块 → 检查数据及来源 → 打开统计工作区。

- 默认传递已确认的生物学单位、归一化值、分组、配对关系和来源。技术重复已汇总的记录不得再次计数或重复归一化。
- 未确认设计的数据可作描述性查看，但推断入口保持与现有 WB 相同的限制。
- 保留未检出、不可计算和排除状态，不将其转换成零。
- WB 来源表默认作为只读来源快照；允许编辑分析范围、显示名称和样式。要更改测量值，返回 WB 修改，或明确复制为独立编辑表并保留派生关系。
- 源 WB 更新后提示“有新源版本”，用户选择更新才替换当前来源版本；既有图形历史继续引用原快照。
- 相同来源和终点可继续打开已有统计表，或明确“另建副本”；不能每次点击都生成重复项目。
- 保留从统计数据返回 WB 原图/泳道的入口。源文件被移动时可重定位；新统计项目的冻结数值仍可使用，并明确原图暂不可访问。

### 3.3 界面布局

| 区域 | 职责 |
| --- | --- |
| 左侧模块区 | Western blot、免疫荧光、统计与绘图；模块切换保留当前文档状态 |
| 左侧项目树 | 数据表、分析结果、图形；按数据表展示关联对象，可另存分析和图形 |
| 顶部工具栏 | 新建表、导入、分析、新建图形、导出、撤销/重做 |
| 中间工作区 | 表格编辑、统计结果表或大幅图形预览，随选中对象切换 |
| 右侧属性区 | 所选数据集、坐标轴、误差线、文字、比较标记的属性 |

首版提供清晰的属性分类和可选中图形对象；之后完善双击、拖动与批量样式操作。所有图形操作都有表单或键盘入口。

## 4. 分阶段范围

### 阶段 A：抽取公共能力，建立数据与版本基础

交付：通用统计/图形数据合同、WB 适配器、新统计项目格式和兼容层。

- 将测量、统计计算、样式渲染的输入及版本拆开；仅修改统计参数无需重新读取 WB 像素，仅修改样式无需重算检验。
- 将原有数值核心抽取为唯一实现，旧 WB 接口通过适配层调用，避免两套算法长期分叉。
- 建立新项目的保存、锁、自动保存、重开、另存、副本身份、冻结版本和来源索引。
- 用固定输入对照抽取前后的结果与旧项目读写；原图与旧图形保持可读。

### 阶段 B：交付首个完整统计与绘图模块

交付范围：

| 分类 | 首版功能 |
| --- | --- |
| 表格 | Column 列式表、明确配对的列式表、宽/长表导入映射 |
| 统计 | 描述统计、Welch t、配对 t、普通单因素 ANOVA、Welch ANOVA |
| 多重比较 | 现有 Holm、Dunnett、Tukey/Tukey–Kramer、Games–Howell；显式展示比较家族 |
| 图形 | 散点与均值、柱形叠加散点、柱形、配对连线 |
| 编辑 | 分组颜色/顺序/别名、散点、误差线、坐标、文字、标注位置、图例及画布尺寸 |
| 统计标注 | 两组和多组统一选择实际对比结果；精确 P 值或星号，保留方法和校正信息 |
| 导出 | PNG、SVG、PDF、Excel、CSV/JSON；可复制方法说明和图注草稿 |
| 保存 | 自动保存、重启恢复、图形历史、另存副本、可追溯的数据来源 |

首版完成的判据：无需任何图像即可从表格做到图和统计报告；已有 WB 数据也能进入相同工作区并得到一致数值。

### 阶段 C：扩展常用实验设计

该阶段分小版本交付，各方法经独立数值核对后开放。

| 数据/设计 | 增加分析 | 增加图形与说明 |
| --- | --- | --- |
| 两组及多组非参数 | Mann–Whitney、Wilcoxon 配对、Kruskal–Wallis 与 Dunn 校正 | 箱线图、适用时的小提琴图；声明检验对象，不能一概解释为中位数检验 |
| 独立两组补充 | 等方差 Student t | 与 Welch 的选择由设计/假设决定，不自动挑选显著结果 |
| XY | Pearson/Spearman、简单线性回归 | 数值 X 轴、散点、拟合线和置信带；连接数据点与模型拟合分开 |
| Grouped 双因素独立设计 | 明确模型下的双因素 ANOVA、交互作用、预设简单效应及校正 | 分组点图/柱图、交互作用图；时间标签本身不等于重复测量设计 |
| 重复测量 | 先支持完整数据的明确设计；不完整或更复杂设计单列后续混合模型 | 主体 ID 与测量时间/条件显式映射，不用逐时点独立 t 替代整体模型 |

每种新方法必须先确定：适用数据、效应方向、缺失处理、精确/渐近/置换计算规则、置信区间、校正范围、数值参考与依赖版本。

双因素模型需明确交互项、非平衡设计的对比编码/平方和规则和简单效应范围；重复测量需明确主体、协方差/球形性处理及缺失策略。未完成这些合同前不显示可运行按钮。

### 阶段 D：完善论文出图与排版

- 批量套用和保存图形模板，统一多图字号、线宽、颜色、坐标与间距。
- 完善双击对象编辑、拖动图例/标注；统计标注只移动位置，不能手填另一个 P 值。
- 多行多列排版、A/B/C 面板编号、对齐与等距、跨图一致样式。
- 组合统计图与现有 WB 条带组图；WB 原图连续裁剪、拼接标识和来源约束沿用现有实现。
- 汇总数据表可作为独立输入类型，以明确的 mean/SD 或 SEM/n 元数据支持已验证方法；不能显示虚构原始点。
- 批量导出、模板版本和整图图注。图注由实际分析元数据生成草稿，不自动补写实验事实。

### 阶段 E：按实际需求增加专项分析

候选包括剂量反应/非线性拟合、列联表、生存分析、混合模型及实验模板。它们不是首版承诺。

可优先评估 WB、qPCR、EdU 阳性率、CCK-8、克隆形成等模板。模板需定义独立单位、原始与派生值、变换和统计尺度，不能只更换标题套用同一个检验。放射剂量曲线、药物 IC50、临床生存曲线分别实现与验收，不混作普通折线图。

## 5. 数据模型与计算依赖

### 5.1 核心对象

| 对象 | 必需信息 |
| --- | --- |
| StatsProject | 项目 ID、名称、格式版本、修订号、数据表/分析/图形目录、保存状态 |
| Dataset | 稳定 ID、数据修订号、表类型、终点/单位、稳定组 ID、观测记录、来源、设计状态 |
| Observation | 观测 ID、数值或缺失状态、组 ID、独立单位 ID、配对/主体 ID、技术重复和批次信息、来源行/ROI、排除状态及理由 |
| PreparationSpec | 样本角色映射、技术重复汇总、所选终点/范围、派生或变换规则；保留原始记录 |
| AnalysisSpec | 方法、数据版本、设计、尺度、对比、校正家族、置信水平及缺失处理策略 |
| AnalysisRun | 不可变运行 ID、输入签名、方法/版本、实际纳入单位、总体及组对结果、效应/CI、P 值、状态、警告与种子 |
| FigureSpec | 图形类型、数据版本、可选分析运行 ID、所选对比 ID、样式、图幅与显示变换 |
| FigureVersion | 数据快照、分析结果快照、样式、渲染与导出文件、版本关系 |

独立单位 ID 在同一数据表中有稳定命名空间，不能仅按可变的行号生成。显示别名、颜色与列位置不改变组 ID；配对/主体关联不靠行位置推断。

`Observation` 保留原始记录；`PreparationSpec` 生成用于计算的独立单位视图。已在 WB 聚合的数据明确标记为独立单位，跳过技术重复汇总，防止二次聚合。

`endpoint` 和 `batch` 是通用概念；WB 的蛋白名/膜/分析块写入来源映射。通用核心不导入 WB 模块。WB 特有的跨膜限制放在适配器中，不能用虚拟单膜 ID 绕过现有限制。

### 5.2 更新规则

| 发生的变化 | 必须更新 | 保留不动 |
| --- | --- | --- |
| 原始值、纳入状态、分组、独立单位、配对或汇总规则改变 | 数据版本及依赖分析的状态 | 已冻结图形和历史结果 |
| 分析方法/尺度/校正家族改变 | 新分析运行及依赖它的活动图形 | 原始测量、无关分析 |
| 颜色、显示名称、组显示顺序、字体、尺寸改变 | 图形渲染/样式版本 | 数据与检验结果 |
| WB 有新结果 | 来源更新提示；显式接收后建立新数据版本 | 未接收更新的图和统计快照 |
| 切换项目、异步结果返回 | 按项目 ID、输入签名和请求序号核对 | 当前项目的新编辑不能被旧响应覆盖 |

活动图形可联动当前已运行分析；数据改变后标记依赖结果过期，不能继续用旧 P 值生成貌似当前的导出。历史图查看和导出始终使用冻结的数值与方法记录。

## 6. 统计结果合同

- 统一输出描述统计、总体检验、组对对比和可读方法说明，分别展示各自的 n、效应、置信区间与 P 值。
- 统一组对方向为 B−A；log2 差及反变换比值分别命名，不把倍数图的显示选择当成分析尺度。
- 两组 t 的普通 95% CI 与多重比较同时 CI 明确区分。Holm 调整 P 值不会自动把现有 t 区间变成同时区间。
- 迁移旧分析时保留原有 family_id 及校正规则；新多组结果不再进入旧 Holm 循环。Games–Howell 仅展示对照比较时，依然保留其全部两两比较家族。
- 新分析运行记录完整预设比较列表。若成员不可计算，保留失败项，首版阻止该新家族产生最终校正结论，不能静默缩小比较家族；旧历史结果按原规则读取并标明版本。
- 数据设计由用户明确；不依据正态性检验自动切换方法，不依据显著性选择方法，不自动删除异常值。
- 缺失、未检出、排除和数值零分别表示；导入错误阻止运行，而不是自动变为缺失。配对缺失/重复可见，不静默丢弃。
- n=0/1 的展示与误差线限制沿用已有规则。每组最低可计算 n 不是功效或实验充分性的保证。
- 每次运行记录数值库版本、有效输入和随机种子。数值近似带相应说明；尚无 Prism 实机对照时不宣称与 Prism 完全一致。

## 7. 论文图与渲染方案

1. 保留 Matplotlib 为首版预览和 PNG/SVG/PDF 的权威渲染来源，先将其输入改为通用 FigureData。前端负责交互，不另算均值、误差线或 P 值。
2. 配对图使用主体/配对 ID 构造连线；通用 FigureData 需保留逐点身份，不能继续只传数值数组。
3. 渲染结果可附对象 ID 与图中边界信息，供前端覆盖选择层定位坐标轴、数据系列、图例和文字；选择层不能改变输出图内容。该方案先做小型技术验证，避免承诺 PNG 自身可直接编辑。
4. 统一图幅单位为 mm，字号为 pt；允许 40–90 mm 等小 panel 宽度，并给出单 panel 与整图预设。默认示例可设 60 × 50 mm，用户可修改。最终排版仍需检查标签与标注是否重叠。
5. 图幅和字号独立于屏幕缩放；PNG DPI 作为栅格输出参数。首版支持 300/600 DPI，在明确像素/内存预算下校验，禁止静默降采样。
6. PDF/SVG 提供文字可编辑与文字轮廓两种明确模式。字体嵌入、中文兼容及外部编辑器表现需验收；不得把“矢量文件”直接等同于“所有文字可编辑”。
7. 新项目可选蓝粉配色 `#88B8D0` / `#E29EB6`，并保留现有黄灰预设；旧图加载自身已存颜色，不自动更换。
8. 首版仅提供已支持的线性显示轴。后续增加对数轴时，区分显示轴变换和检验尺度，并处理非正值。图幅裁剪、零基线截断、标注越界可见。
9. 图注和方法说明来自实际数据/分析/样式配置。包含独立 n、误差线类型、检验与校正、分析尺度和符号定义；不根据结果显著与否删改输出事实。

## 8. 文件、兼容与模块划分

### 8.1 项目保存

- 首版采用便携 `.titanstats` 文件夹，包含项目清单、版本化数据、分析运行、图形快照和必要来源元数据。
- `.titanwb` 保持现有身份和打开路径；旧图形使用兼容读取器。旧 WB 生成的新统计项目是可追溯副本，不破坏性改写原项目。
- 统计项目中保存计算必需的数据；外部原图路径仅作来源导航，不作为打开冻结数值的唯一依赖。需要完整原图打包时走明确导出选项。
- 本地索引增加项目种类；无种类字段的旧索引按 WB 读取。索引迁移保留备份、原子写入和跨进程锁；旧应用不保证能读取新统计格式。
- 复用或抽取现有原子文件写入、会话锁和并发版本检查机制。来源移动、损坏、只读、保存失败均有明确状态，不静默清空目录或索引。

### 8.2 建议代码边界

| 位置 | 职责 |
| --- | --- |
| `src/stats/` | 独立模块入口、数据表、分析编辑器、结果视图、状态与导航 |
| `src/figures/` | 可复用图形属性、来源显示、尺寸设置、选择层与图形文档；从现有组件逐步抽取 |
| `src/types.ts` 及新增通用类型文件 | 保留 WB 类型兼容，增加统计项目和统一结果合同，避免强行修改所有旧接口 |
| `backend/titan_stats/` | 通用数据校验、数据准备、统计核心、图形模型/渲染、统计项目保存、导入导出 |
| `backend/titan_wb/stats_adapter.py` | WB 到通用数据的适配、独立性/跨膜校验、来源追溯及旧结果字段映射 |
| `backend/titan_wb/engine.py` | 首版保留现有引擎分发入口，新增 `stats_*` 命令，避免同步改动桌面启动协议 |
| `library.py` 和现有前端项目库 | 支持两类项目与混合导航；按项目种类调用相应保存/读取器 |

目前已有 SciPy、NumPy、Matplotlib、openpyxl，可支撑首版。表格组件、双因素模型、非参数后续比较及混合模型若需新依赖，先核对维护情况、许可证、离线打包和原生兼容；此计划不预设未经核对的版本。

### 必须覆盖的首版场景

- 独立三组 Excel 粘贴 → ANOVA/多重比较 → 图中调整 P 值 → 保存 → 重启恢复 → 导出。
- 两组独立值 → Welch → 图上精确 P 值/星号；明确区分普通 CI 与 Holm 校正 P 值。
- 配对数据乱序后按 ID 正确配对、连线与计算；不完整配对可见阻断。
- WB 定量转入 → 技术重复不增加 n → 返回原图 → 更新源数据 → 旧图保留。
- 同一数据表产生两个分析与两个图形；改图 A 的样式不改变图 B 或统计结果。
- 改数据使依赖分析过期；快速切表或切项目时，旧异步结果不能覆盖新上下文。
- 三组数据存在空组、单值、非法数值或排除记录时，位置/原因可见，不伪造零值或误差线。
- 旧 `.titanwb`、旧冻结图、另存副本、源文件移动、只读锁和损坏索引均可明确处理。
- 60 × 50 mm 小图、中文/长标签、3/5/8 组、比较标记密集、300/600 DPI 与 PDF/SVG 字体检查。
- 导出的图、Excel 数据、分析结果、方法说明均引用同一数据与分析版本；同配置 PNG 预览/导出一致。

### 数值与交付验证

- 延用已有手算 ANOVA、Welch ANOVA、配对 log2、Holm 与公开多重比较参考数据，新增迁移适配与图形标注交叉验证。
- 新统计方法必须有独立来源的参考结果或手算/独立实现对照，不能只调用相同库两次自证正确。近似算法给出容差并记录原因。
- 后续实现按影响范围运行 Vitest、pytest、构建与 Playwright；完成首版再执行全量回归和 Windows/macOS 原生验收，不把浏览器通过等同于桌面已验证。
- 使用隔离的测试项目目录，不写入用户当前应用的数据目录。保留本工作区已有未提交修改，禁止为实施计划清空或回退其他工作。
- 原计划不代表验收记录；本轮实际完成的测试及限制见 `docs/checkpoint-reports/statistics-v04.md`。
