# Titan 项目结果与统计工作区对接

日期：2026-11-07（Asia/Shanghai）。基础：`a4c0711`，包含 beta3 与统计模块。用户已授权计划后执行，并更新本机 Titan 主应用。

## 使用流程

统计首页及侧栏增加“从项目读取结果”，列出已有 WB / IF 项目，也允许选择磁盘上的项目目录。选择项目后预览可用指标、分组、有效样本数、缺失数及来源版本。用户选择一个或多个指标，确认统计单位后，新建关联统计项目或添加到当前项目。

WB、IF 结果页均可“发送到统计与绘图”，进入同一指标选择流程。来源栏支持返回原模块、检查来源版本及显式更新。`.titanstats` 的直接打开与外部表格导入继续保留。

## 数据规则

- WB 复用现有归一化与独立单位汇总，按目标蛋白 / analysis block 生成数据表；保留跨膜限制和明确的配对 ID。
- IF 复用现有 Python 生物学汇总，按通道 / 采集批次 / 指标生成数据表。支持原始平均强度、扣背景总强度、阳性面积比例、核阳性率；比例明确换算为百分数。原始均值按面积加权，阳性比例合并分子与分母，不平均各视野百分比。
- 不将核或视野数作为独立 n；每格代表 bio_id。相同 bio_id 跨组可按 ID 对齐，不能按显示顺序推断配对。不同批次分表。
- 不兼容的分析方式或阈值、过期结果、缺失样本身份阻断对应数据读取。某样本部分视野未测量时，该样本保持缺失并说明原因；缺失值和零分母不替换为零。
- 预览与确认导入之间校验来源签名，避免导入用户未确认的新版本。
- 保存来源项目身份、路径、版本、指标、原始汇总记录及签名；关联测量值只读。更新只替换当前关联表，保留旧分析与冻结图；不静默更新。来源丢失时仍可使用已存快照。

## 验收

- 无需导出 Excel，即可在统计模块选择已保存的 WB/IF 项目和指标。
- IF 多视野数据只贡献一个生物学样本值，百分比计算有独立数值基准。
- 来源更改可检测、手动刷新后旧分析失效，冻结图保持原值；来源路径指向不同项目时拒绝刷新。
- 新旧 `.titanstats` 可保存、重开、绘图和导出；原 WB/IF 项目不被统计模块改写。
- 保留开始时已有的图像指引改动。本任务不实现跨批次模型、IF 自动配对推断或新的统计检验。
