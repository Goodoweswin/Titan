# Titan WB macOS Desktop App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 默认由当前代理顺序执行；只有用户或适用skill要求时才使用子代理。

**Goal:** 交付可安装、离线双击运行的macOS WB分析桌面App，从TIFF/PNG到可审核定量、图表、完整项目与数据导出。

**Architecture:** Python科学计算与Qt原生界面分离。领域状态保存在本地项目中，所有异步计算与导出绑定输入revision；图像显示不修改定量像素。

**Tech Stack:** Python 3.11、PySide6/Qt Widgets、NumPy、Pillow、tifffile、SciPy、Matplotlib、pytest/pytest-qt、PyInstaller。

**Spec:** `docs/superpowers/specs/2026-10-21-wb-app-design.md`。本计划是待确认设计的实现提案，未开始执行产品代码。

## Global Constraints

- 输入原始WB TIFF/PNG，首版为macOS桌面App，当前arm64机器先构建验收。
- Python 3.11；依赖解析后保存精确锁文件与许可证清单，不依赖用户另装Python。
- 原图字节、位深、原图坐标不可由预览调整改变；不静默转换多通道/多页。
- ROI为0起点 `[x0,y0,x1,y1]`，右下边界不包含；拒绝越界、空框和背景重叠。
- 不截断负净信号，不给分母添加epsilon；确认/QC门槛随项目与导出保存。
- 技术重复不增加独立n；统计输入、显示fold change、IBC与配对关系分开保存。
- 本地单写入者、原子保存、异步过期结果丢弃；原图hash不匹配时停止旧分析。
- 默认上限单文件50 MiB、单平面25,000,000像素；不隐式缩图绕过。
- `.app`/`.dmg`必须离开源码目录实际启动验证；真实数据准确性另行验收。
- 每个CP结束运行该阶段检查及所有已存在回归，写报告后才更新唯一状态表 `docs/checkpoints.md`。

## Review Focus

1. 16位TIFF/PNG、暗条带与未知ADC上界不会被Qt预览误改或猜测——CP2/CP5测试。
2. 缩放后编辑、撤销与任务晚到不会套用错ROI、样本或旧审核——CP3/CP4测试。
3. 同一bio多膜、多技术泳道、缺失/错误IBC不会虚增n或伪造可合并性——CP6测试。
4. 零分母、退化统计、配对缺失与共享对照分母不会生成误导性结果——CP5/CP7测试。
5. 中文路径、只读/损坏项目、关闭时任务未完成与安装后缺依赖不会丢分析——CP2/CP8/CP9测试。

## 类型和跨CP接口约定

所有路径下列均相对于项目根。`src/titan_wb/domain/models.py`定义：

- `Rect = tuple[int,int,int,int]`。
- `ImageAsset(id, relative_path, sha256, width, height, dtype, polarity, ceiling, acquisition_metadata)`。
- `Sample(id, bio_id, group, pair_id, kind, pool_id)`；kind为biological/ibc，pool_id仅对ibc适用；`Lane(id, membrane_id, sample_id, technical_id)`；ID是身份，显示位置不是身份。
- `BandROI(id, image_id, lane_id, analyte, role, rect, backgrounds, reference_id, reviewed_revision)`；role为target/reference，未审核为None。
- `AnalysisBlock(id, membrane_ids, pooled_reference_id, merge_same_sample)`；默认单膜、不合并。跨膜block须显式配置。
- `AnalysisSettings(control_group, normalization_mode, ibc_by_membrane, analysis_blocks, comparison_specs, linearity_notes)`；`ibc_by_membrane: dict[str,dict[str,str]]`为膜ID→终点→显式IBC目标ROI ID，引用的样本须为kind=ibc并有匹配pool_id。
- `ProjectState(id, schema_version, revision, name, images, samples, lanes, rois, settings)`；schema_version初始1，revision非负递增。
- `Measurement(roi_id, input_revision, area_px, raw_sum, background_mean, corrected_sum, clipped_fraction, flags)`。
- `NormalizedValue(roi_id, lane_id, sample_id, bio_id, membrane_id, analyte, group, normalized, bridged, flags)`。
- `BioValue(sample_id, bio_id, pair_id, group, analyte, membrane_id, analysis_block, value, n_technical, flags)`。
- `ComparisonSpec(id, family_id, group_a, group_b, test, scale)`；test为descriptive/welch/paired，scale为raw/log2。
- `StatsResult(comparison_id, n_a, n_b, effect, statistic, df, p_raw, p_adjusted, ci95, warnings)`。
- `AnalysisResult(project_id, input_revision, measurements, normalized, biological, statistics)`。

模型字段允许None的位置以设计文档为准，禁止任意NaN混入JSON；未计算、被阻止与不适用必须有显式状态/原因。`from_json(data: dict) -> ProjectState`与`to_json(state: ProjectState) -> dict`为唯一持久化入口。
