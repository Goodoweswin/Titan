## 2. 首版范围与完成定义

首版包含：本地项目创建/重开；原始图像管理；原图与预览分离；原图坐标的 ROI 和背景编辑；撤销/重做；候选条带建议；逐条审核；灰度定量和QC；目标/参考匹配；技术重复与生物学单位；同膜对照、显式IBC桥接；受限的两组统计；图表；可追溯数据导出；macOS安装包。

“自动处理”在v1中是自动建议与批量计算，目标蛋白身份、样本映射和异常数据由用户确认。机器学习模型可作为后续替换检测器；首版不承诺无需人工校正的任意图像识别。

首版不含云账户、多人协作、仪器控制、专有仪器格式、任意旋转/非刚性校正、多因素或纵向混合模型。多页/多通道输入先明确拒绝并给出灰度导出说明；文件不可被默默降为8位。Windows/Intel Mac的支持另设真实构建环境后验收。

1. **工程完成**：CP1–CP9测试通过，生成当前macOS Apple Silicon的 `.app` 和 `.dmg`，安装后可离线双击运行，无Python安装要求。

## 3. 实现选择（Tauri已确认）

- Tauri 2桌面外壳，React + TypeScript + Vite界面。
- SVG/Canvas工作台负责预览和ROI；只保存原图整数坐标。
- Python 3.11与NumPy、Pillow、tifffile、SciPy、Matplotlib负责科学计算。
- Python引擎经PyInstaller打包为随App分发的本地sidecar，用户无需安装Python。
- 界面通过受限Rust命令调用引擎，采用stdin/stdout JSON协议；无常驻HTTP服务器。
- 计算请求绑定project_id/revision，过期结果丢弃。单次进程超时终止，退出无残留服务。
- pytest、Vitest、Playwright分别覆盖计算、前端状态和浏览器交互；macOS安装后的真实Tauri窗口另行验收。
- CP1就打通真实计算引擎与最小.app打包，CP9完成DMG与独立路径验收。

采用这一方案是为了保留Python计算逻辑，同时使用Web界面技术实现完整桌面工作台。当前机器为macOS arm64。

官方依据：[Tauri sidecar](https://v2.tauri.app/develop/sidecar/)、[macOS打包](https://v2.tauri.app/distribute/macos-application-bundle/)。macOS原生Tauri窗口测试不以浏览器测试代替。

## 4. 用户工作流与主要交互

1. 新建或打开本地实验项目，导入原始图。
2. 设置图像极性、有效编码范围和曝光信息；未知值可保存，结果显示探索性状态。
3. 填写样本、组别、独立生物学单位、技术重复、原膜与原始泳道；明确目标和参考图的对应关系。
4. 框定目标区域，自动提出候选，也可手工画框。缺失条带保留缺失，不从邻道补值。
5. 调整ROI与背景，逐项复核。支持撤销/重做，图像缩放不会改原图坐标或数值。
6. 计算原积分、背景、净积分和QC；阻止不适用的比例计算，但保留原始记录。
7. 选择上样参考/总蛋白/总目标蛋白，预览技术重复汇总与生物学样本数。
8. 明确单膜/多膜、IBC、配对和统计尺度后计算结果；不支持的设计仍可导出原始表。
9. 保存、退出、重新打开，以及导出数据、图表、原图/ROI叠加与审计记录。

界面主要文案使用中文；蛋白名、样本ID允许英文和中文。分析步骤之外只展示能帮助用户决定的参数，不把运行时或依赖信息放进日常操作路径。

## 5. 定量与科学边界

### 5.1 像素与ROI

- 支持单平面8/16位整数灰度TIFF/PNG，以及已明确数值语义的有限浮点灰度TIFF。
- TIFF Photometric、有效位数、格式限制必须显式解析；不支持的编码应拒绝，不静默反相。
- 保留原始字节及SHA-256；显示拉伸只作用于预览，不改原图和积分。
- ROI为0起点 `[x0,y0,x1,y1]`，右下边界不包含。越界、空框、背景重叠为错误。
- 亮信号使用I，暗信号使用C−I。C需明确；不得由当前图像最大像素猜测。
- 净积分=信号积分−条带像素数×背景并集均值。保留负数，不逐像素截零。
- 标准矩形ROI为默认；每个lane/终点/role只有一个正式ROI。同一终点的框选规则应一致。
- smear可作为用户指定的单个矩形区域测量；多个独立条带分别设为不同终点。v1不支持把任意多个ROI相加后当作同一终点，避免合计与分母定义不明确。

### 5.2 确认、QC与版本

- 候选框初始均为待复核，不能自动变成已确认。
- 目标/背景/极性/样本/参考发生变化时，旧复核和相关结果失效。
- 数字信号端clipping、非正净信号、参考错配、未复核阻止默认归一化。
- 未知clipping或未记录线性范围验证时，允许探索性结果，但状态随导出保留。
- 原文件hash改变/文件丢失时停止使用旧测量并给出恢复选择。
- `linear_range_validated`保存为用户实验声明及备注，不把布尔字段当作程序验证。
- 不依据正态性检验自动选择检验，不自动删除离群值或选择最显著的背景算法。

### 5.3 归一化与重复

- target/reference明确引用ID；须对应相同sample、bio、膜和原始lane。
- 目标和参考允许分属不同采集图。显示序号不能替代原始lane身份。
- 技术重复先在同膜、同样本/终点内取净信号比值均值，再进入生物学汇总。
- 同膜对照的分母为等权生物学单位均值，不因技术泳道较多而改变权重。
- IBC模式显式选择每膜同一份 pooled reference 的目标/参考比值；计算N_sample/N_IBC。
- IBC样本类型为reference pool，带相同pool_id；每膜每终点显式选一个已复核的IBC目标ROI。IBC不计入生物学n，不进入处理/对照统计。
- 缺少/失效IBC、跨膜终点不一致、分组与膜完全混杂时，阻止相应合并分析。
- 同一bio在多膜重复出现不能重复计入n。默认保持分膜；用户显式建立AnalysisBlock并选择合并后，须各膜使用同一pooled reference进行IBC桥接。
- 合并顺序固定为：同一sample/膜/终点内技术泳道比值等权平均 → 除以本膜IBC比值 → 同一sample跨膜结果等权平均。这样技术泳道多的膜不会额外加权；n按bio而非膜或lane计数。
- v1在同一group/终点内，每个bio只允许一个sample ID；同一样本的技术aliquot使用同sample ID和不同lane。出现不同sample ID但重复bio时，要求修正样本/重复关系，不擅自合并不同组织或时间点。配对条件用不同group及明确pair_id。
- p/total与total/loading作为不同终点，避免不清楚的重复除内参。

### 5.4 v1统计

- 同膜：两独立组Welch t；明确配对的两组配对t。用户选择原始正比值或log2尺度，默认仅作描述性汇总，选择检验后说明适用设计。
- 统计输入为生物学单位的归一化值，不使用人为恒为1的对照点，图表fold change与检验输入分开记录。
- 最少2个有效独立单位/组或2个完整配对才可数值求解；这只是软件可计算条件，不是样本量充分性的声明。
- 检查独立性、重复身份、配对完整、零方差/退化输入；不适用时输出原因，不输出伪精确p值。
- IBC跨膜的默认输出为描述性结果；v1不对多个膜简单汇总后进行无批次项t检验。
- 一批预先选定比较为一个比较family；可选Holm校正，保留原始和校正p值及family ID。
- 图表显示生物学散点，配对连线；可选SD或95%CI并明确标注。

参考：[SciPy Welch参数](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind.html)、[SciPy配对t](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_rel.html)。WB方法依据保存在 `wb_research/WB分析流程与研发资料.md`。

## 6. 本地项目与执行状态

项目使用可移动文件夹，后缀 `.titanwb`：

```text
experiment.titanwb/
  project.json       # schema_version、revision、样本、ROI、审核、分析设置
  originals/         # 按image_id保存的原始文件
  results/           # 关联input revision的计算产物
  backups/           # 最近可恢复的manifest
```

导入时复制原图并核对hash，避免源路径移动后丢图。manifest通过同目录临时文件+原子替换保存；应用崩溃不能破坏上一次有效保存。原图缺失/hash不符、未知schema、只读目录均有可理解的错误。

同一个项目仅允许一个写入者；存在锁时先以只读打开，不能静默夺锁。恢复陈旧锁需确认原写入者已不存在。自动保存采用明确的revision；关闭窗口若有未保存变化提供保存/放弃/取消。

后台任务绑定 `(project_id, project_revision, image_id)`，取消或输入变更后丢弃旧结果。运行失败不替换上一次有效结果；批量任务逐图记录失败，不悄悄漏项。

v1导入上限暂定单文件50 MiB、单平面25,000,000像素，均为工程默认值并在导入前告知。超过上限保留原文件并返回原因；不通过隐式缩图绕过限制。

## 7. 导出与安装交付

导出包必须包含测量表、归一化表、生物学汇总表、统计设置/结果（若有）、排除原因、ROI/背景坐标、软件和算法版本、配置、输入与输出hash。正式结果文件关联相同revision，不能混合新旧版本。

图表为PNG和SVG；叠加图清楚区分目标、背景、待复核与不适用数据；不生成替代原图的“修复条带”。纯合成示例始终标记非实验数据。

安装包必须在脱离源码目录的路径上启动、导入示例、保存、关闭/重开、导出，再退出重启；不能仅凭打包命令退出码判定成功。离线运行不下载模型和依赖。
