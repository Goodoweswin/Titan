# Titan 课题项目与分析侧栏设计

用户确认采用类似 thread 的组织方式。项目由用户手动创建，一个项目能容纳多次 WB、IF 和独立统计分析。分析可随时恢复，正式图与导出物在项目中直接可达。既有已登记的分析先归入「未归类」，由用户决定归属。

## 用户操作

- 固定的「项目 ＋」在 WB、IF 和统计工作区中提供「新建项目」「新建 WB 分析」「新建 IF 分析」「新建统计分析」「打开已有分析」。新建项目只填名称，可为空容器。新建分析先确认名称与归属，当前项目内发起时默认该项目，其他入口默认「未归类」。可在同一对话框内新建归属项目，取消时不创建分析或项目。主页新建按钮使用同一流程。
- 展开项目可直接看到「分析」和「图表与导出」两组条目。点击分析默认回到上次成功打开的页面，缺失页面回到工作台。工作台、结果、组图仍有直接跳转入口。搜索匹配项目名、分析名和产物名，清除后恢复展开状态。当前分析或图表始终高亮。
- 项目菜单提供改名、置顶和移出列表。移出项目时提示其中分析会回到「未归类」，可在创建项目后重新归类。分析菜单提供「移到项目」「在文件管理器中显示」，原有另存入口保留。一个分析最多属于一个项目，同名课题和同科学 ID 的分析副本按独立 ID 区分。另存分析副本默认继承课题归属，副本作为独立分析显示。置顶优先，其余按最近打开排序，自动保存不改变顺序。
- 正式图显示名称、来源分析和版本。项目产物列表汇集分析自身已经保存的 WB 柱图、WB 条带组图、独立统计的图形快照和成功导出的结果与图文件。IF 当前论文组图仍从分析打开，成功导出的 IF 图登记为冻结产物入口。预览和未保存草稿不入库。打开旧图使用已有历史版本或实际导出文件，进入源分析是单独动作。导出记录标明源分析、实际导出时的版本及输出位置。外部文件找不到时仍能看到其记录并回到来源。升级时恢复 Titan 已有来源记录的产物，未登记的旧导出留在原位置。独立统计分析后续引用多个来源时，图表归属其创建分析，来源链接保留各自身份。

## 存储和范围

课题归属是本地项目库元数据。以稳定的 `entry_id` 关联课题、分析和导出入口，沿用现有路径登记和文件锁。归类只写索引，实际分析目录、原图、样本、测量及各自的历史保持原位置。课题使用独立 ID 和名称，旧索引按缺省字段读取，缺失文件保持原归属并可重新定位。同一个已登记路径再次打开时保留原归属。成功打开或切换后才登记续做位置，保存失败或迟到的加载不会切走当前工作。

沿用 WB 和 IF 各自的项目格式、科学计算与保存流程。独立「统计与绘图」采用统计预览分支 `a4c0711` 已有的 `.titanstats` 格式，使用同一个本地索引登记分析、归属、数据表续做位置、冻结图与导出。由 WB 发送的统计分析保留已登记的 WB 来源身份，新建时继承来源课题。历史统计导出绑定原运行版本。默认采用一层课题，所有资料保存在本机。

## 验收样例

手动建「皮肤衰老」，放入一条 WB 和一条 IF 分析，再把其中一条改归「水凝胶」。退出重开后，列表与归属一致，旧图能打开原版本，导出入口仍指向原文件。用旧索引开始、同时登记与移动、重新定位、另存同 ID 副本、切换前保存失败、外部导出丢失也各有明确的预期。
