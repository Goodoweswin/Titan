# Titan 分析可视化更新设计

用户已授权「给出更新计划，然后执行」。保持 Tauri、React、Python 和浅色大字号界面，直接执行此前讨论的三项改进。

## 行为
- 选择 ROI 后，可展开强度曲线。按该 ROI 的 x 范围，在原始图像完整 y 轴上计算逐行平均信号；暗条带按声明 ceiling 转换。曲线显示 ROI 区间和显式背景框并集的平均值。积分数值复用 measure，保留负值；缺少/无效背景显示原因，不伪造零基线。预览与正式分析独立，不改变项目或复核状态。
- 图表导出先打开模态预览。使用与最终 PNG/SVG 相同的 Python 绘图函数，可设每个面板宽度、整图高度、字号与 DPI。设置写入导出审计。预览不写入用户目录；输入/设置变化时隐藏旧预览并禁用确认。保持已有 CSV、原图、审计导出。
- 自动识别返回临时候选，画布以虚线展示，用户可取消部分候选或全部丢弃；确认后才创建 ROI/泳道，之后沿用手动编辑、背景和复核流程。输入版本变化使临时候选失效；空结果有清晰提示。

## 实现决定
- 保留当前未提交工作，在当前目录实现，不创建丢失现有改动的独立 checkout，不自动提交既有修改。
- 不新增依赖；SVG 绘制曲线，Matplotlib 负责真实导出预览。不引入机器学习模型。
- 曲线超过 1200 行时按桶返回平均值及极值用于显示，积分始终使用全部原始像素。
- 配色沿用现有 tokens；曲线蓝色、背景橙色，标签与数值使用当前字号体系。面板可折叠，小窗口允许自然纵向滚动。

## 验收
真实 Python 引擎合成数据测试：16 位、暗极性、负信号、重叠背景、缺失背景和坏 hash；导出预览与最终 PNG 相同设置/尺寸；浏览器检查选中联动、旧异步响应不覆盖当前状态、候选确认/取消/撤销、预览和大字号布局。真实 WB 准确性仍需另行实验验证。
