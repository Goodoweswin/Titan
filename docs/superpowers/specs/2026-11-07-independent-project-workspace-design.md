# Titan 独立项目工作区设计

项目是可独立打开的工作区。它可以先只有一个名称，也可以存放资料、多个分析以及这些分析的图表和导出。分析有自己的工作记录，可以归入一个项目，也可以独立保存。Western blot、免疫荧光和统计与绘图是开始分析的工具入口。

参考 [ChatGPT Projects](https://help.openai.com/en/articles/10169521-projects-in-chatgpt) 的组织关系。项目中的资料与会话是分开的，全局和项目内都能开始新会话，已有会话可移动。Titan 将会话对应为分析，将项目文件对应为项目资料。

## 工作区与入口

| 操作 | 打开的页面或记录 | 归属与数据 |
| --- | --- | --- |
| 点击左栏「新建项目」 | 输入名称后进入项目主页 | 创建一个空项目 |
| 点击左栏「新建分析」 | 选择 WB、IF 或统计 | 默认独立保存，可在创建时选择归属 |
| 在项目主页点「新建分析」 | 使用同一套分析选择入口 | 预选当前项目，选择可见且可更改 |
| 点击 WB／IF 工具入口 | 进入该工具的简介和导入页 | 从此导入默认独立保存，打开工具首页不会创建记录 |
| 点击已有分析 | 进入该记录所属的工作台并恢复视图 | 打开原分析、图形和保存状态 |
| 分析菜单中「移到项目」或「移出项目」 | 原分析按新归属显示 | 更新分析的归属，原文件与分析结果保留 |

应用首页提供「新建分析」和「新建项目」。左栏的「项目」列出项目工作区，点击名称打开主页，折叠箭头控制分析条目的展开。「独立分析」是一组可重开的分析记录。项目和分析分别使用「打开项目」和「打开分析」等可见文案及无障碍名称。分析行显示 WB／IF／统计标签，主要用名称辨识。工具入口属于全局导航，即使从某个项目切过去，项目归属也不会自动跟随。

项目主页包含「资料」「分析」「图表与导出」。返回主页时，三类内容的范围由项目 ID 决定。项目可以只有资料或只有分析。项目内启动分析后，工作台显示分析名称、类型和所属项目，可回到原项目主页。全局「打开已有分析」重新打开已登记的条目，首次打开的外部分析作为独立分析登记。

工具主页以用途简介和明确的导入按钮为主。导入到新分析沿用 WB 的 TIFF 页选择、IF 的通道和序列选择、统计的表格导入规则。取消文件选择或首次导入验证失败时，不留下空分析记录。显式「新建分析」允许创建暂时没有数据的记录。

## 项目资料与分析数据

项目资料由用户显式添加，属于项目自身。第一版提议默认登记原文件路径，保留文件名、稳定 ID 和用于校验的摘要。该决定待用户确认。可登记图像、表格等本地普通文件，具体工具在导入时检查格式。文件移动或内容变化时保留原登记，使用时提示重新定位原件或另加文件。项目资料不依赖分析，也不跟随分析在项目之间移动。打开工具、创建分析或导入到分析都不会自动改动资料列表。

从资料启动分析时，由用户选择要使用的文件和分析工具。分析通过各模块现有导入器建立自己的输入记录，继续使用既有的原图校验、可携带保存和结果快照。两份分析可以使用同一份项目资料，分别保存设置和结果。分析中的导入文件也可以始终只在该分析中使用。

从 WB／IF 结果启动统计时，延续现有来源追溯。由项目内的结果页发起时，当前项目作为可见的默认值。独立统计入口读取另一个项目的结果时，分析归属继续由当前入口决定。往已有统计分析中添加来源时，保持该统计分析的归属。

图表和导出通过原分析登记。项目页根据当前归属汇总这些产物，移出项目后仍能从独立分析打开。移除项目的动作需在确认框说明，项目内分析转为独立分析，项目的资料登记从项目库移除，原文件保留。

## 兼容与实现边界

现有项目库已存有独立项目 ID 和分析的可选归属。以现有 `LibraryCollection`、`LibraryEntry.collection_id` 和 `index.json` 为基础，补充项目资料和可打开的项目视图。保持旧项目 ID、分析 ID、归属、结果和续做位置。没有资料字段的旧项目按空资料列表显示，原有输入从各分析继续访问。首次读取旧索引无需改写磁盘。

项目主页的导航状态与活跃分析、工具首页分别表示。统一外层导航，沿用各工作台的保存与关闭保护。重用已有项目库锁和原子写入机制。项目资料添加、定位及分析归属是显式写操作。应用启动时以索引元数据展示资料列表，文件读取和校验发生在用户主动使用时。

已有 `.titanwb`、`.titanif` 和 `.titanstats` 文件继续按原方式打开和保存。项目归属不通过修改分析文件夹来实现。第一版适用于本机项目库，跨设备搬运项目资料需根据已确认的存储方案另行设计。科学计算继续由已有工具执行。

## 验收

1. 新建空项目后可以进入其主页。未启动分析时可添加资料。退出再打开，项目和资料仍在。
2. 项目 A 登记一份图像，切到 WB、IF、统计入口再回来，项目资料清单、原文件校验值和已有分析结果一致。
3. 从全局工具入口导入文件，独立分析可保存和重开，项目 A 的资料清单不增项。取消导入无空记录。
4. 从项目 A 创建两个不同工具的分析，能从项目主页分别继续。把其中一个移出项目后，分析仍可重开，项目 A 的资料和另一分析保留。
5. 项目内打开已有图形和导出时，定位到原分析及对应版本。老索引与三个分析格式可打开。缺失项目资料只影响该资料的使用。
6. 在旧工作台有未保存修改时，使用项目主页、全局入口和模块简介离开，仍按原保护规则处理。
