# WB 条带组图：默认排版与手动调整

日期：2026-11-02
状态：用户于 2026-11-02 确认执行；功能实现与验证见对应实施计划。

## 用户确认的范围

- 生成完整的 WB 条带组图。
- Titan 提供默认排版，用户自行进行精细调整。
- 沿用 WB 免费的定位，本地运行。

## 目标

用户从同一实验的原始图像裁出多个蛋白区域，生成包含蛋白名、完整横向条带区域、样本/处理条件和分子量标注的组图。默认版式尽量直接可用；保存后可以继续修改，并导出供后续精细编辑。

不与柱图、散点图组合；不要求先完成定量或统计检验。不加入账户、订阅或云上传。

以下未由用户逐项指定的版式、操作和存储选择均为本设计建议。

## 默认版式

- 白底，黑色无衬线文字。
- 每个蛋白对应一行：左侧蛋白名，中间横向裁剪图，右侧可选分子量文本，单位 kDa。
- 上方一个共享的样本/处理条件标签区域；按选定的样本列位置显示。支持手填文本，包括 Ctrl、剂量、时间、＋/−。
- 图像区左右边界一致；默认目标蛋白在前，内参在后；用户可以改行顺序。
- 默认总宽 85 mm、文字 8 pt、行间距 3 mm。图像保持原始宽高比，行高由裁剪区比例和共同图像显示宽度决定，不能为了等高而拉伸条带。
- 基于原始图像比例布局。泳道间距在不同原图上不同的情况，不通过局部拉伸强行对齐；用户复核裁剪和列标签位置。
- 多行属于不同来源时保持明显行间距；不会拼装成看似连续的一张膜。

## 用户流程

1. 打开已有实验，进入独立的“WB 组图”入口，创建一个组图文档。
2. 选择要展示的蛋白行。已有 band set 可作为候选：以对应窗口或覆盖选中泳道的整块区域提出裁剪，用户必须在原图上确认。只导入了原图而未分析时，也允许手动添加行、填写蛋白名、框选裁剪区域。
3. 一行裁剪始终是一块连续的矩形，可包含多个泳道和多个可见条带；不把各泳道单独截取再拼接。
4. 自动生成默认版式，带入已确认的蛋白名和可用样本标签；未知标签留空。冲突的样本顺序不能静默覆盖，提示用户核对，并允许直接编辑显示标签。
5. 用户调整裁剪、行顺序、蛋白名、分子量、顶部文字及其水平位置、图像区宽度、行间距、字号。
6. 保存组图；重新打开后保留原图关联和编辑状态；导出 PNG、SVG 和来源说明。

入口建议作为项目内独立视图，能从现有项目界面到达，不占用统计图设置。空项目给出“请先导入原图”的引导。

## 手动调整的边界

- 行可添加、移除、上移、下移；允许一张原图贡献多个不同裁剪行。
- 裁剪在原图预览上操作，坐标可数字微调；不可越界，宽高必须为正。
- 调整图像整体显示宽度时同步保持每行比例；不会独立移动、修补、复制、删除某一条实验条带。
- 顶部标签可手填，并按图像区的相对横向位置调整；默认位置仅在样本映射清楚时自动带入，否则按用户指定列数等分。
- 分子量第一版为用户填写的文本，不自动查询蛋白数据库或自动估算；允许为空。可以填写一行期望的蛋白大小，也可添加多个带位置的 marker 标注，两者在编辑界面中明确区分。marker 位置绑定该行裁剪坐标，修改裁剪后同步映射或提示其已超出范围，不能错误地留在原位置。
- 提供恢复默认版式；保留已确认的图源、裁剪、标签内容和行顺序，只重置宽度、字号、间距等样式参数。
- 撤销/重做覆盖本编辑器内的文档修改，不修改定量 ROI 或已有统计图。
- 不提供任意泳道重排/拼接、局部亮度修饰、AI 生成条带、自动选择“代表性实验”。需要更复杂的图形布局时使用导出的 SVG。

## 图像显示与数据来源

- 原始文件只读；裁剪、显示和标注是独立元数据。
- 组图使用源图当前明确记录的整体旋转/显示方向，裁剪坐标统一绑定到该显示坐标系；记录原始文件、页号、旋转角和坐标转换，避免旋转后裁错区域。
- 默认沿用源图的已有显示映射并固定记录参数；若无法复用，则使用全幅图统一线性映射，不按单个裁剪或泳道分别自动增强。不新增可调对比度功能。
- 不改变定量输入、定量 ROI、泳道身份、结果数值或已有结果有效性。
- 记录原图 ID、文件哈希、页号、原始尺寸、裁剪矩形、显示变换、用户文本、布局参数和文档版本。
- 组图行保存来源快照。原图从当前列表移除后，仍保留被文档引用的项目原图；修改当前分析布局不自动修改已保存组图。
- 原图缺失、哈希变化或不支持的格式明确报错，不能静默替换图源或导出空白图。

## 保存与导出

- 与实验一起保存在 `.titanwb` 项目内。组图文档使用独立类型/目录，不把它假装成需要 AnalysisResult 的柱图文档。
- 建议放在 `figures/wb/` 下，独立目录索引，避免改变现有统计图 catalog 的解析约定；沿用项目锁、原子写入和源图保留逻辑。
- 进入编辑器可有草稿；明确的“保存组图”创建可恢复的文档版本。切换实验或离开编辑器时，提示保存或放弃未保存修改。
- 文档名称可编辑。同一实验可以保存多个组图，且可从该实验的组图列表重新打开。
- 项目另存副本、迁移、重开时保留文档及引用原图；只读项目可以预览和导出，不能覆盖保存。
- PNG 默认 300 DPI，可选 600 DPI，物理尺寸与预览一致。显示原始像素在最终尺寸下的有效分辨率，升高 DPI 不宣称增加真实细节。
- SVG 包含嵌入式位图和可编辑文字；不能依赖本机绝对图片路径。用户可在外部矢量编辑软件中继续精调。
- 来源说明 JSON 随导出保存，说明每行图源、哈希、裁剪坐标与变换、布局、分子量输入类型、用户标签；合成数据保留可见的“非实验数据”标识。
- 预览与导出使用相同布局定义和渲染规则；导出所见即所得，不能导出此前其他文档的缓存。
- 导出目的地由用户选择，避免静默覆盖已有成果；保存组图文档与导出图片是两件独立操作。

## 实现者可以决定的细节

沿用 React / TypeScript、Tauri 与 Python 本地引擎。具体组件拆分、布局算法、目录索引格式、预览缓存和 SVG/PNG 共用渲染方式由实现者决定，前提是满足上述文档独立性、坐标一致性和数据完整性要求。第一版使用表单与裁剪交互即可，不要求开发通用矢量绘图软件。

## 验收依据

- 未进行定量的实验也能从原图新建、保存、重新打开、导出完整组图。
- 多蛋白与内参按默认格式生成，手动标签、顺序、尺寸、间距、裁剪可调整，恢复默认只重置样式。
- 用人工构造的有可识别像素/泳道顺序的图像验证裁剪、页号、旋转坐标、显示映射、marker 位置与导出对应一致；原图字节不变。
- PNG 的物理尺寸/DPI 与 SVG 布局一致，SVG 离开项目目录后仍显示位图与可编辑文本。
- 保存、另存副本、迁移、原图移出当前分析列表、只读和损坏源图场景符合预期；已有定量、统计图和项目文档仍能重开使用。
- 切换项目、异步预览返回和未保存草稿不得串入其他项目或覆盖其他文档。
- 自动化与合成图片验证只支持软件行为判断；真实 WB 图像的最终呈现还需要人工核对。
