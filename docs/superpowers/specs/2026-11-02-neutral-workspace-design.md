# Titan 中性工作区界面

用户已认可对照截图提出的方向，并要求“计划然后执行”。本设计直接进入实施，不再增加审批轮次。

## 意图与范围

统一应用外壳、顶部操作、主导航和 WB 组图页面。参考用户给出的 Codex 管理页的清晰层级与克制用色，保留 Titan 图像工作台的画布宽度、大字号、键盘可用性和既有数据流程。保持现有图标资源，不更换品牌，不改变定量、裁剪、保存和导出算法。

## 设计选择

- 画布/内容白 `#ffffff`，侧栏浅灰 `#f6f6f5`，正文 `#202123`，辅助文字 `#6b6d6b`，分隔线 `#e6e7e5`；图像交互强调蓝 `#4167c4`。主要动作使用正文深色，蓝色集中用于图像选区、聚焦和少量交互提示。
- 系统字体（macOS 系统字体及苹方，Windows 使用现有后备字体）。正文 14px，辅助 12–13px，实验名 18px，页面名 20px；用 rem 定义随大字号模式放大。
- 常用按钮约 32–36px 高；普通按钮减少边框，选中导航使用清楚的灰色底或深色下划线。保持可辨识的 hover、disabled 与 focus-visible。
- 上方一行标题和操作，下方一行普通视图导航；去掉重复实验标题块和 01–04 步骤装饰。
- 名称仍可直接编辑；保存与另存副本保留有名称的可访问按钮。导入、定量、结果导出按当前视图出现；WB 组图的保存/导出留在组图工具栏。
- 引擎状态、原图/条带/复核数量及原始像素说明统一放入底部状态栏；合成数据和只读标记始终清楚可见。
- 当前蛋白选择与主导航处于同一上下文区域，避免新增第三层高大的标题条。

```text
侧栏          实验名 / 保存状态          字号  保存  副本  当前视图操作
              内参   目标   结果   WB 组图       [当前蛋白（适用时）]
              ---------------------------------------------------
              页面标题 / 简短说明                    本页操作
              画布或结果内容                     紧凑设置区
              ---------------------------------------------------
              图源 / 复核数              本地引擎 / 原始像素提示
```

## WB 组图

- 空白时只有一个“新建组图”按钮，标题、说明和按钮居中为一组，去掉大虚线容器。
- 有已保存组图时才展示文档选择器；现有组图可从空白页打开。创建草稿后显示紧凑的文档工具栏。
- 编辑时图页为白底，外部工作底色为浅灰，设置区使用标题和留白分组，不堆叠卡片。
- 创建、已保存文档切换、保存、导出、撤销和草稿保护保留；保存实验与保存组图的名称明确区分。

## 自检与边界

不能把管理页的窄内容栏套在图像工作台上；不使用巨大营销式空白区或无用装饰。只读、错误和合成数据提示不为视觉简化而隐藏。小屏允许操作换行，页面无整体横向溢出；结果表和图像画布可在各自容器内滚动。

## 验收

检查标准/大字号、1440 与 1080 桌面宽度及 390px 窄屏；空白 WB 页面一个创建按钮且组内对齐；实验标题与导航只占两行；名称编辑、保存/副本、导入、定量、结果导出和组图草稿保护有效。保存前后不改变科学输入或文件格式。通过完整测试、截图检查和独立审阅后更新本机 App，保留旧版备份。
