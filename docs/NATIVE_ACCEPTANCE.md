# 原生桌面验收清单

以下原生窗口操作仍待实机验收。公开测试包支持 macOS 14+ Apple Silicon 和 Windows 10/11 x64；当前未配置 Apple 公证或 Windows 商业代码签名。CI 中的引擎检查不代替这份原生操作验收。

1. 打开对应的 Mac DMG 或 Windows 安装程序，在不覆盖已有试验项目的前提下安装/启动；离开源码目录操作，不启动开发服务器。
2. 等待“本地引擎就绪”，打开合成示例并定量。确认 24 测量、12 目标、1 条饱和阻止、6 生物学单位；示例始终标注“非实验数据”。
3. 导入一张已知 8 位 PNG 和一张 16 位 TIFF，检查错误输入提示、预览与原数据区分。多页 TIFF 应先选页；彩色页应明确拒绝，灰度调色板可导入。
4. 放大并画目标/背景框，移动/调整坐标，撤销/重做，设置极性/编码上界与样本/参考。内容变化后复核与旧结果应失效。
5. 保存至中文路径的 .titanwb 文件夹，修改并等待自动保存；退出再打开，确认图像、坐标、样本和审核版本一致。
6. 计算并导出到新中文目录；检查 CSV/JSON/PNG/SVG/原图/叠加/audit 全部存在，已有目录不能被覆盖。
7. 未保存时关闭窗口，确认放弃/取消行为；关闭后重启，无残留写入锁阻止正常重开。运行中的计算退出后无常驻服务。
8. 使用项目副本测试：另一写入进程占锁时只读；旧进程退出后可恢复；损坏 manifest 且有有效备份时恢复至新副本，不改原损坏文件。
9. 若使用多图/跨膜实验，核对原泳道引用、IBC pool、技术权重及分块图表。真实数据科学验收另按 CP10 执行。

记录操作时间、系统版本、使用的包 hash、期望/实际结果和截图。任何未执行项保留待验收。


## 0.2 泳道优先更新的追加验收

- [ ] 安装包从独立目录启动，不依赖源码/系统 Python；整个会话只使用一个引擎 PID。
- [ ] 灰度调色板与 16 位多页选择可用；显示反色不改变测量结果。
- [ ] 三步流程可通过拖选区域走通，正常路径无需像素坐标或高级参数。
- [ ] 内参确认后添加两个目标，样本和泳道对应不变；中间未检出仍保留空位。
- [ ] 可调整泳道/峰区/背景、排除 marker；取消或切换后不写入迟到结果。
- [ ] 保存重开与审计导出含布局、页码、样本名、缺失状态和正确比值。
- [ ] 旧项目升级保存到新副本，原文件保持不变。
- [ ] 应用退出后引擎退出；异常 worker 可恢复，保存/导出不自动重复执行。

平台与实际验证记录见 `docs/checkpoint-reports/lane-first-update.md`。浏览器测试、原生 GUI 验收和独立 Fiji 对照分别记录，不能互相替代。

## 0.3 项目库、图形与统计追加验收

- [ ] 新实验立即入库；编辑后自动保存，退出/重开仍可从左栏回到项目。保存失败不能丢修改。
- [ ] 同名项目、同ID副本、中文路径、移动后重新定位均可区分；另存包含原图及冻结图版本。
- [ ] 三组独立合成设计：Dunnett对照、Tukey全两两、Welch/Games–Howell，方法说明与n相符。
- [ ] 自选颜色/HEX、标题、误差/散点/轴/字体，取消草稿与迟到预览不污染其他项目。标准/大字号可用。
- [ ] 左栏打开旧图保留源；重设样式不换数据；明确更新源后仍可打开旧版本。
- [ ] Excel 12表数值、空值、统计家族/同时CI、配置与PNG/SVG一致；Excel/矢量软件实开检查。

本轮只保留0.3.0更新包，不覆盖正在运行的应用；自动浏览器/打包引擎检查不计为以上原生操作完成。
