# 原生桌面验收清单

以下原生窗口操作仍待实机验收。公开测试包支持 macOS 14+ Apple Silicon 和 Windows 10/11 x64；当前未配置 Apple 公证或 Windows 商业代码签名。CI 中的引擎检查不代替这份原生操作验收。

1. 打开对应的 Mac DMG 或 Windows 安装程序，在不覆盖已有试验项目的前提下安装/启动；离开源码目录操作，不启动开发服务器。
2. 等待“本地引擎就绪”，打开合成示例并定量。确认 24 测量、12 目标、1 条饱和阻止、6 生物学单位；示例始终标注“非实验数据”。
3. 导入一张已知 8 位 PNG 和一张 16 位 TIFF，检查错误输入提示、预览与原数据区分。彩色/多页文件应明确拒绝。
4. 放大并画目标/背景框，移动/调整坐标，撤销/重做，设置极性/编码上界与样本/参考。内容变化后复核与旧结果应失效。
5. 保存至中文路径的 .titanwb 文件夹，修改并等待自动保存；退出再打开，确认图像、坐标、样本和审核版本一致。
6. 计算并导出到新中文目录；检查 CSV/JSON/PNG/SVG/原图/叠加/audit 全部存在，已有目录不能被覆盖。
7. 未保存时关闭窗口，确认放弃/取消行为；关闭后重启，无残留写入锁阻止正常重开。运行中的计算退出后无常驻服务。
8. 使用项目副本测试：另一写入进程占锁时只读；旧进程退出后可恢复；损坏 manifest 且有有效备份时恢复至新副本，不改原损坏文件。
9. 若使用多图/跨膜实验，核对原泳道引用、IBC pool、技术权重及分块图表。真实数据科学验收另按 CP10 执行。
