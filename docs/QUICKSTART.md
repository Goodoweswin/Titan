# 快速上手

## 用内置教程完成一次 WB 分析

1. 打开 Titan，在 Western blot 工具页点击「教程」。示例是合成数据。
2. 在「目标」页按提示选择图像区域，核对泳道和识别出的峰区、背景，再点击「确认目标」。
3. 到「结果」查看各泳道的测量。教程素材提供目标测量练习，结果中的目标与内参比值留空。
4. 打开「WB 组图」，新建组图，确认裁剪，保存并导出。

## 使用自己的图像

1. 从首页新建项目，选择 Western blot。导入内参原图，核对泳道、候选条带和背景后确认内参。
2. 添加目标图像，核对它与内参的泳道对应关系，逐个确认目标。
3. 在「结果」中核对样本分组、重复单位和归一化结果，再保存项目或导出结果。

## Excel 数据清洗

从左侧「工具」打开「数据清洗」。选取 Excel 后依次核对表头、样本分组、单位和重复记录。确认预览，再把结果送入统计。本地整理可直接使用。选择 OpenAI 映射建议时，使用自己的 API Key，并可在发送前查看和编辑将要提交的表头摘要。
