# 统计与绘图预览版

基于 `v0.4.0-beta.2`（`3d8872c`）开发，独立分支 `codex/statistics-v04`。本预览使用应用名 **Titan Stats Preview** 和独立应用数据标识，保留原 Titan 安装及其项目。

## 开始使用

1. 左侧选择“统计与绘图”，新建项目，或体验明确标注为非实验数据的合成示例。
2. 直接编辑列式表，或选择“导入 / 粘贴”。CSV/TSV/Excel 支持宽表；长表使用 `group,value,unit_id`，可增加 `pair_id`。XLSX 可选择工作表。不执行公式，缺少公式缓存值会提示改为粘贴数值。
3. 每格输入独立生物学单位的数值；技术重复先按实验设计汇总。配对必须有明确 ID。右键单元格可以排除/恢复。空格是缺失，不等于零。支持矩形粘贴、行列增删和撤销/重做。
4. 在“统计分析”选择描述统计、Welch t、配对 t、普通单因素 ANOVA 或 Welch ANOVA，核对分析尺度、对照与比较范围，确认独立单位后运行。
5. 在“图形”选择图型、误差线、精确 P 值/星号及需要显示的组对。可编辑颜色、显示别名、顺序、点形、线宽、坐标范围，以及以 mm 为单位的最终图幅。
6. 保存图形快照可固定当时的数据、分析与样式；修改当前数据不会覆盖它。旧分析可在历史中查看，也可以复制为新表。
7. 导出到新的文件夹，得到 PNG、SVG、PDF、Excel、CSV、分析 JSON 与方法说明。SVG 可选可编辑文字或轮廓模式；PDF 使用嵌入 TrueType 字体，外部编辑器表现仍需按实际软件检查。

## 与 WB 衔接

WB 结果页新增“发送到统计与绘图”。传递的是独立单位归一化结果及来源，技术泳道不增加 n。已有对应统计项目时打开它；当前 WB 新结果需要在来源栏明确“用当前 WB 更新”。旧图形保留原数据。

来源表的测量值与组别只读；需要改值时返回 WB，或复制为可编辑表。返回 WB 与更新来源需要原项目可访问。统计快照可以独立重开。跨膜数据继续保留现有限制，不能作为无批次项的普通独立检验输入。

## 方法与图形解释

普通 ANOVA 与对照比较采用 Dunnett，全部两两比较采用 Tukey/Tukey–Kramer；Welch ANOVA 后采用 Games–Howell。后者即使只展示对照比较，校正家族仍包含全部两两比较。两组单一预设对比不额外校正。旧 WB 的显式 Holm 家族逻辑保留。

图上的每组均值 CI 与组间差异 CI 不同；两组 t 的 CI 是普通区间，多组方法提供同时区间。log2 是分析尺度，图中继续显示录入的原始测量值，并在方法说明中标明检验尺度。颜色和显示顺序不会更改检验。

## 当前范围与后续任务

已实现独立项目、公共统计核心、宽/长表输入、可编辑图形、来源关联和快照。支持从数据表建立多个历史分析和多个图形快照；同一表当前只有一套活动分析设置。

仍待完善：独立的多分析对象编辑、通用技术重复汇总向导、可配置跨表 Holm 家族、图形对象的直接点击/拖动、图形模板与多面板排版、免疫荧光数值直接转入。XY、双因素、非参数、重复测量和专项分析仍属于后续阶段，不在本预览中开放。旧 WB 统计入口继续兼容保留。

保存失败或版本冲突会明确提示，不能静默覆盖。当前保留上一份清单备份，尚未提供统计项目损坏备份恢复向导。

## 验证边界

自动化覆盖独立数值参考、旧 WB 回归、导入、配对、保存冲突、来源表只读、失效结果、导出格式，以及真实 Python 引擎驱动的 React 组件流程。macOS 原生预览已检查独立入口、合成表、ANOVA（F=7，P=.027）、图形、尺寸和快照保存。

Playwright 浏览器测试因本环境禁止监听本地端口而未完成；新增测试保留在仓库。Windows 原生包、完整跨平台操作验收、与 Prism 实机逐项对照尚未完成。此构建用于预览，不宣称完成全部规划阶段。
