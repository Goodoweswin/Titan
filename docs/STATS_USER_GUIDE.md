# 统计与绘图

在「统计与绘图」工具页可以直接导入 Excel、CSV 或粘贴数据来创建独立分析。也可通过「新建分析」选择归属，或打开之前保存的 `.titanstats`。各构建和本机安装状态见 [版本注册表](releases/INDEX.md)。

## 开始使用

1. 左侧选择“统计与绘图”，新建项目，或体验明确标注为非实验数据的合成示例。
2. 直接编辑列式表，或选择“导入 / 粘贴”。CSV/TSV/Excel 支持宽表；长表使用 `group,value,unit_id`，可增加 `pair_id`。XLSX 可选择工作表。不执行公式，缺少公式缓存值会提示改为粘贴数值。
3. 每格输入独立生物学单位的数值；技术重复先按实验设计汇总。配对必须有明确 ID。右键单元格可以排除/恢复。空格是缺失，不等于零。支持矩形粘贴、行列增删和撤销/重做。
4. 在“统计分析”选择描述统计、Welch t、配对 t、普通单因素 ANOVA 或 Welch ANOVA，核对分析尺度、对照与比较范围，确认独立单位后运行。
5. 在“图形”选择图型、误差线、精确 P 值/星号及需要显示的组对。可编辑颜色、显示别名、顺序、点形、线宽、坐标范围，以及以 mm 为单位的最终图幅。
6. 保存图形快照可固定当时的数据、分析与样式；修改当前数据不会覆盖它。旧分析可在历史中查看，也可以复制为新表。
7. 导出到新的文件夹，得到 PNG、SVG、PDF、Excel、CSV、分析 JSON 与方法说明。SVG 可选可编辑文字或轮廓模式；PDF 使用嵌入 TrueType 字体，外部编辑器表现仍需按实际软件检查。

## 直接读取项目结果

进入“统计与绘图”后点击“从项目读取结果”，在项目库中选择 WB / IF 项目，也可浏览已保存的 `.titanwb` / `.titanif` 目录。勾选指标，核对各组有效 n、缺失值及单位，确认统计单位后读取。可新建统计项目，或添加到当前统计项目。从全局工具页读取时默认独立保存；从 WB 或 IF 结果发送时默认选择来源分析所在项目。新建时可以修改归属。已有同一来源指标保留原快照。

WB 与 IF 结果页的“发送到统计与绘图”进入同一个选择窗口。先保存原模块中的修改，再读取保存后的结果。

| 来源 | 选择范围 | 每个数值代表什么 |
| --- | --- | --- |
| WB | 目标蛋白、分析块 | 已确认的独立生物学单位，技术泳道先汇总 |
| IF | 通道、采集批次、指标 | 同一 bio_id / 分组 / 批次的全部定量视野汇总 |

IF 支持原始平均强度、扣背景总强度、阳性面积比例和核阳性率。均值按测量面积加权；比例合并分子与分母后计算，显示单位为 %。不同采集批次分表。核阳性率要求核模式、已确认分割及阳性阈值。

未完成测量、缺少通道结果或零分母保持缺失，不补零；同一样本部分视野未完成时，不用剩余视野冒充完整样本。过期结果、不兼容阈值或缺少生物学身份会提示返回 IF 复核。配对依据明确样本 ID，不能按行序推断。跨膜 WB 数据继续保留原有限制，不作为无批次项的普通独立检验输入。

## 来源更新与历史

来源表的测量值、样本编号和组别只读，图形样式仍可编辑。来源栏显示原项目、指标、批次与来源版本，可“返回 WB / IF”检查原始分析；需要自由改值时使用“复制为可编辑表”。

统计表保存的是关联快照。来源变化后，切回窗口或点击“检查来源更新”会提示变化；点击“用当前 WB / IF 更新”才刷新当前表，并要求重新运行分析。历史分析与已保存图形快照保留原数据。来源文件移位时，先在左栏重新定位原分析。来源文件暂不可访问时，已有统计快照仍可打开、分析和导出。

读取项目不会修改原 WB / IF 项目。预览与确认读取之间校验来源版本，防止读取未经确认的新结果。

## 方法与图形解释

普通 ANOVA 与对照比较采用 Dunnett，全部两两比较采用 Tukey/Tukey–Kramer；Welch ANOVA 后采用 Games–Howell。后者即使只展示对照比较，校正家族仍包含全部两两比较。两组单一预设对比不额外校正。旧 WB 的显式 Holm 家族逻辑保留。

图上的每组均值 CI 与组间差异 CI 不同；两组 t 的 CI 是普通区间，多组方法提供同时区间。log2 是分析尺度，图中继续显示录入的原始测量值，并在方法说明中标明检验尺度。颜色和显示顺序不会更改检验。

已实现独立项目、公共统计核心、宽/长表输入、可编辑图形、来源关联和快照。支持从数据表建立多个历史分析和多个图形快照；同一表当前只有一套活动分析设置。

保存失败或版本冲突会明确提示，不能静默覆盖。当前保留上一份清单备份，尚未提供统计项目损坏备份恢复向导。

## 验证边界
