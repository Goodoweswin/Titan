# 二维免疫荧光使用指南

本模块是独立于 WB 的开发版功能。真实 IF 分割准确性和 Windows 原生验收尚未完成。合成示例不是实验数据。

## 开始与导入

1. 左侧选择「免疫荧光」，点击「新建 IF 实验」；也可先点「体验 IF 合成示例」。
2. 点击「导入 IF 视野」，选择原始 TIFF / OME-TIFF。多个分通道文件可明确组合成同一视野。
3. 确认图像序列、维度和通道。Z / T 含多个平面时必须选择一个平面；没有可靠轴信息的多页图须手动指定轴，页不能直接视为通道。
4. 填写视野、样本、生物学样本、分组与采集批次。多个视野属于同一样本时使用相同生物学样本编号；缺失编号的视野不会进入生物学样本汇总。
5. 核对 X、Y 的 µm/px；缺失时使用像素单位，不生成微米比例尺。尺寸或标定不一致的分通道图不能直接叠加。

支持单通道数值 TIFF、独立通道 TIFF、多通道 OME-TIFF。RGB TIFF 仅供显示与组图，不能转成原始荧光定量。CZI / LIF / ND2 先用 Fiji Bio-Formats 转为保留位深、通道与标定的 OME-TIFF。外部像素文件的多文件 OME 清单、64 位整数图不受支持。

初始资源限制：四个通道、单边不超过 4096 像素、单文件不超过 2 GiB；原始解码预算 256 MiB、计算预算 1 GiB。超限请先用 Fiji 拆分。

## 区域强度与阳性面积

选择「区域强度与阳性面积」，在原图画矩形、椭圆或多边形信号区域，再绘制独立背景区域。坐标保存在原始像素空间；缩放不改变区域位置。

点击「测量当前视野」。原始平均强度为像素和除以像素数；扣背景积分为原始像素和减去区域像素数乘背景均值，负值保留。多个背景区域按像素并集计算，不重复加权。无背景时仍可报告原始强度，扣背景值留空；没有信号区域时测量全视野中背景以外的部分。

阳性面积需要填写目标通道的原始强度阈值与来源，并勾选「冻结阳性阈值」。阈值应由同批次阴性对照等依据确定。区域模式只输出阳性面积比例，不产生核阳性率。

## DAPI 核分析与人工修正

1. 切换「DAPI 核与核内阳性率」，指定核通道和测量目标通道。
2. 调整平滑、阈值、核面积、核间距与边缘对象规则，点击「分割细胞核」。可选滚动球只影响分割，不修改强度测量图。
3. 逐一检查彩色核标签。可补核、选择后删除/合并，或画线拆分；「撤销核编辑」可恢复上一次标签版本。
4. 密集图只显示前 3000 个编号，但点击原图像素可选中任何核；显示的核总数包含全部标签。
5. 人工修正或撤销后需要重新点击「确认分割」，再「测量当前视野」。

核阳性判定使用目标通道原始核内均值与冻结阈值比较。DAPI 分割代表细胞核，不代表完整细胞；胞质/膜信号首版使用区域分析。

通道颜色、亮度上下限与可见性只改变显示。分析参数、区域或核标签改变后，旧测量失效；影响核分割的设置改变后需要重新分割。

## 批处理与结果

先在代表视野上验证设置，再「复制设置到同批次视野」。通道按名称匹配，冻结阈值不能跨采集批次复制；各视野的区域仍需分别检查。

「批量测量」保留各视野设置。核模式需先逐视野确认核标签。失败视野显示错误并保持缺失；不会记作零。取消后结果不会自动写入项目，当前后台计算将在安全检查点退出。

「IF 定量结果」提供对象、视野和生物学样本表。每个生物学样本是一个独立统计点；区域强度按有效像素汇总，阳性比例合并分子与分母，不把细胞或视野数量当生物学 n。测量方式/阈值来源不兼容的数据不会静默混合。

对象表每视野最多预览前 500 条，全项目最多预览 5000 条；导出保留完整对象表。超出 JavaScript / Excel 精确整数范围的积分以十进制文字保留末位。首版不提供显著性检验。

## 独立论文组图

无需定量即可进入「IF 论文组图」。选择样本行、通道列和 Merge，设置原图裁剪坐标、局部放大插图、字号与输出宽度。通道名和视野名用于标注。

按相同通道名锁定跨视野显示范围。设置比例尺前核对所有选中视野标定；移除标定后，可用「移除比例尺」清除原比例尺。预览采用有界分辨率，导出仍使用设置的实际尺寸和 DPI；来源图像像素不会因组图改动。

组图导出 PNG、TIFF、SVG 与来源记录。SVG 内显微图像为位图，文字、比例尺和标注保留为可编辑元素。结果导出对象/视野/样本 CSV、Excel、样本散点图与来源记录；区域模式散点使用阳性面积比例，核模式可使用核阳性率。

## 保存、移交与验证边界

项目自动保存为 .titanif 文件夹，也可手动保存。移交时复制整个文件夹，包含 originals、masks、results、history；这些文件保留原图、人工核标签、完整结果和历史。不要只复制 project.json。原图或正式结果的校验值改变时，会停止使用。

已完成合成数据测试和独立 ImageJ 核心同掩膜算术对照。真实 IF 准确性仍需至少 20 个代表视野、覆盖三个生物学样本，并有独立人工标注；声明支持的图像类型以 IoU≥0.5 匹配后 Precision/Recall≥0.90 为初始验收线。此门槛不等同于任意标记、仪器或组织上的泛化保证。
