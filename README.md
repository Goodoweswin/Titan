# Titan downloads

Mac and Windows installers: https://github.com/Goodoweswin/Titan/releases

This branch contains public release metadata only. Titan continues to provide free local analysis without a mandatory account. New source development is private; historical MIT source and releases retain their original licenses.

The Beta update feed remains at https://raw.githubusercontent.com/Goodoweswin/Titan/updates/beta.json.

A GitHub-generated Source code archive for a new release contains this distribution metadata, not the private application source. Runtime licenses and third-party notices are included with the installers.
